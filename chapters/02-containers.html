CHAPTER 02

容器：list、dict、set、tuple

容器决定了数据如何组织、访问和修改。AI 项目中的文档、模型响应、配置和检索结果几乎都建立在这些结构之上。

学完你应该能够：根据需求选择容器；熟练索引、切片、增删改查和遍历；理解浅拷贝、可变性与常见组合。

必须掌握的术语

术语 准确理解
sequence 有顺序、可索引的序列，例如 list 和 tuple。
index / slice 单个位置访问与区间访问；索引从 0 开始。
mapping 键到值的映射，dict 是核心实现。
hashable 具有稳定哈希值、可作为 dict 键或 set 元素的对象。
mutable 可原地修改，例如 list、dict、set。
comprehension 列表、字典和集合推导式。
shallow copy 只复制最外层容器，内部对象仍共享。
unpacking 把序列或映射拆分到多个变量或参数。

1. list：有序、可修改

chunks = ["第一段", "第二段", "第三段"]
print(chunks[0])       # 第一段
print(chunks[-1])      # 第三段
print(chunks[0:2])     # 新列表

chunks.append("第四段")
chunks.extend(["第五段", "第六段"])
removed = chunks.pop()
print(len(chunks), removed)

2. dict：用键表达数据含义

document = {
    "text": "Embedding 是文本的向量表示",
    "source": "notes.md",
    "score": 0.91
}
print(document["text"])
print(document.get("page", "未知页码"))

document["page"] = 3
for key, value in document.items():
    print(key, value)

document["page"] 在键不存在时抛 KeyError；get() 可以提供默认值。需要发现数据错误时使用前者，需要容错时使用后者。

3. set：去重与集合运算

required = {"Python", "NumPy", "Git"}
learned = {"Python", "Git", "RAG"}

print(required & learned)  # 交集
print(required - learned)  # 尚未掌握
print(required | learned)  # 并集

shape = (32, 768)

    return min(values), max(values)

low, high = min_max([3, 8, 1])

5. 推导式与排序

scores = [0.52, 0.91, 0.78]
high_scores = [s for s in scores if s >= 0.75]

results = [
    {"text": "A", "score": 0.52},
    {"text": "B", "score": 0.91}

ranked = sorted(results, key=lambda item: item["score"], reverse=True)

6. 浅拷贝问题

original = [{"score": 0.8}]
copied = original.copy()
copied[0]["score"] = 1.0
print(original)  # 也变成 1.0，因为内部 dict 共享

import copy
deep = copy.deepcopy(original)

常见错误

  • 遍历 list 时同时删除元素，导致跳项。
  • 把 list 作为 dict 的键：list 不可哈希。
  • 认为 set 保持业务顺序；集合不应承担顺序语义。
  • 用 {} 创建空 set；它实际是空 dict，空集合应写 set()。
  • 混淆 append 和 extend。
