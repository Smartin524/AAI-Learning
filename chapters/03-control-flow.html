CHAPTER 03

判断、循环与程序流程

控制流让程序根据条件选择路径，并重复处理一组数据。写对控制流的关键不是记语法，而是明确状态、边界和停止条件。

学完你应该能够：组合 if/elif/else；正确遍历容器；使用 break、continue、range、enumerate、zip；避免死循环和边界错误。

必须掌握的术语

术语 准确理解
condition 求值为真或假的表达式。
branch 根据条件选择的执行分支。
iteration 循环的一次执行。
iterable 可以逐个取出元素的对象。
break 立即退出当前循环。
continue 跳过本次循环剩余代码。
range 惰性产生整数序列。
enumerate / zip 同时取得索引；并行遍历多个序列。
short-circuit and/or 在结果已确定时停止计算。

1. 条件分支

score = 0.82
if score >= 0.8:
    label = "高度相关"
elif score >= 0.5:
    label = "可能相关"
else:
    label = "不相关"
print(label)

条件按顺序检查，命中第一个真分支后停止。因此范围更严格的条件通常写在前面。

2. 布尔组合与短路

text = "RAG"
score = 0.9

if text and score >= 0.8:
    print("有效的高分结果")

user = None
name = user.get("name") if user is not None else "匿名"

3. for：遍历而不是手动管理索引

chunks = ["第一段", "第二段", "第三段"]
for index, chunk in enumerate(chunks, start=1):
    print(index, chunk)

scores = [0.7, 0.9, 0.8]
for chunk, score in zip(chunks, scores):
    print(chunk, score)

4. break、continue 和循环 else

results = [0.4, 0.65, 0.92]
for score in results:
    if score < 0.5:
        continue
    if score >= 0.9:
        print("找到高置信结果")
        break
else:
    print("没有找到高置信结果")

循环的 else 只在循环没有被 break 终止时运行。

5. while：依赖状态停止

attempts = 0
max_attempts = 3
success = False

while attempts < max_attempts and not success:
    attempts += 1
    success = call_service()
print("尝试次数：", attempts)
当遍历已知集合时优先使用 for；当重复次数取决于动态状态时才使用 while。

常见错误

  • if score: 只能检查真假，不能代替明确阈值。
  • 多个独立 if 与 if/elif 语义不同：前者可能执行多个分支。
  • range 右边界不包含在内。
  • while 忘记更新状态，形成死循环。
  • 用 for i in range(len(items)) 处理普通遍历，增加越界风险；优先直接遍历或 enumerate。

分层练习

基础
  1. 将分数分类为高、中、低三个等级。
  2. 使用 enumerate 打印文档编号。
进阶
  1. 从检索结果中找第一个超过阈值的结果，否则输出拒答。
  2. 实现最多三次重试，成功后立即停止。
掌握标准
  1. 解释循环 else 的触发条件。
  2. 重构一个嵌套三层的条件流程，使其更易读。
