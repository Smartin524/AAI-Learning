CHAPTER 05

字符串、文件、路径与 JSON

知识库首先是文件和数据。你需要可靠地处理路径、编码、文本清洗与 JSON 序列化，并保持原始数据可追溯。

学完你应该能够：使用 pathlib 安全操作路径；读写 UTF-8 文本和 JSON；理解序列化、编码、上下文管理器和数据验证。

必须掌握的术语

术语 准确理解
path 文件系统中的位置；绝对路径与相对路径语义不同。
working directory 相对路径解析时使用的当前目录。
encoding 字符与字节之间的映射，UTF-8 是通用选择。
text / bytes str 是字符文本；bytes 是原始字节。
serialization 把内存对象转换成可存储或传输格式。
JSON 跨语言文本数据格式，支持对象、数组、字符串、数字、布尔和 null。
context manager 用 with 确保资源正确打开和关闭。
metadata 描述数据来源、页码、时间等信息的数据。
glob 按文件名模式查找文件。

1. pathlib 与相对路径

from pathlib import Path

project_dir = Path(__file__).resolve().parent
data_dir = project_dir / "data"
data_dir.mkdir(exist_ok=True)

for path in data_dir.glob("*.txt"):
    print(path.name, path.suffix, path.stat().st_size)

脚本从不同目录启动时，裸写 Path("data") 可能指向不同位置。项目代码应明确路径基准。

2. UTF-8 文本读写

path = data_dir / "notes.txt"
path.write_text("第一章：变量\n第二章：容器", encoding="utf-8")
text = path.read_text(encoding="utf-8")
lines = [line.strip() for line in text.splitlines() if line.strip()]

3. JSON 序列化

import json

document = {
    "text": "Embedding 是文本向量",
    "source": "notes.txt",
    "page": 3,
    "tags": ["RAG", "NLP"]
}
json_path = data_dir / "document.json"
json_path.write_text(
    json.dumps(document, ensure_ascii=False, indent=2),
    encoding="utf-8"
)
loaded = json.loads(json_path.read_text(encoding="utf-8"))

dumps/loads 操作字符串；dump/load 操作已经打开的文件对象。

5. JSON Lines

# 大量记录适合一行一个 JSON 对象
with (data_dir / "chunks.jsonl").open("w", encoding="utf-8") as f:
    for chunk in chunks:
        f.write(json.dumps(chunk, ensure_ascii=False) + "\n")
RAG 数据应保留 source、page、chunk_id 等 metadata，否则答案引用无法追溯。

常见错误

  • 省略 encoding，在不同系统上出现乱码。
  • 把 Windows 反斜杠直接写入普通字符串，触发 \n 等转义；使用 pathlib。
  • 尝试把 NumPy array、Path、datetime 直接 JSON 序列化。
  • 覆盖原始文件，导致清洗过程无法审计。
  • 假定 JSON 的键一定存在而不做数据验证。
  • 一次性读入超大文件造成内存问题。

分层练习

基础
  1. 扫描目录中的所有 txt 文件并统计字符数。
  2. 将结果保存为 UTF-8 JSON。
进阶
  1. 构造包含 source、page、chunk_id 的 JSONL 数据集。
  2. 跳过无法解码的文件并记录错误日志。
掌握标准
  1. 解释工作目录变化为何会导致 FileNotFoundError。
  2. 为知识库设计可追溯的文档数据 schema。
