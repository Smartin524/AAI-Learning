CHAPTER 08

HTTP、API 与模型调用

API 是应用连接模型、数据库和外部服务的边界。可靠调用需要理解 HTTP、JSON、身份验证、超时、错误码、重试和成本。

学完你应该能够：解释请求和响应；使用 requests 调用 JSON API；安全管理密钥；处理超时、限流、服务端错误与流式响应概念。

必须掌握的术语

术语 准确理解
API 软件之间约定的调用接口。
endpoint 某项资源或操作的具体 URL。
HTTP method GET、POST、PUT、PATCH、DELETE 等请求语义。
header 请求或响应的元数据。
body / payload 发送的数据主体，常为 JSON。
status code HTTP 结果分类：2xx、4xx、5xx。
authentication 证明调用方身份，常使用 API Key 或 OAuth。
timeout 等待连接或响应的最大时间。
rate limit 服务允许的调用频率或配额。
idempotency 重复执行相同请求是否产生相同副作用。

1. 请求与响应结构

import requests

response = requests.get(
    "https://api.github.com/repos/langgenius/dify",
    headers={"Accept": "application/vnd.github+json"},
    timeout=10
)
response.raise_for_status()
data = response.json()
print(data["name"], data["stargazers_count"])

raise_for_status() 会把 4xx/5xx 转成异常，避免把错误页面当正常数据继续处理。

2. POST JSON

payload = {
    "model": "example-model",
    "messages": [{"role": "user", "content": "解释 RAG"}],
    "temperature": 0.2
}
response = requests.post(
    "https://example.com/v1/chat",
    json=payload,
    headers={"Authorization": f"Bearer {api_key}"},
    timeout=(3, 30)
)

使用 json=payload 会自动序列化并设置 Content-Type；data= 的语义不同。

3. 环境变量管理密钥

import os

api_key = os.environ.get("MODEL_API_KEY")
if not api_key:
    raise RuntimeError("请设置 MODEL_API_KEY 环境变量")

4. 状态码策略

范围 含义与处理
200-299 成功，仍需验证响应字段。
400 请求参数错误，修复请求，不应盲目重试。
401/403 认证或权限问题。
404 资源不存在或路径错误。
429 被限流，按 Retry-After 或退避重试。
500-599 服务端暂时错误，可有限重试。

5. 有限重试与指数退避

import time
import requests

for attempt in range(3):
    try:
        response = requests.get(url, timeout=10)
        response.raise_for_status()
        break
    except (requests.Timeout, requests.ConnectionError):
        if attempt == 2:
            raise
        time.sleep(2 ** attempt)
LLM 调用还要记录：模型名、输入/输出 token、延迟、费用、请求 ID和错误类型，才能定位质量与成本问题。

常见错误

  • 不设置 timeout，程序可能无限等待。
  • 把 API Key 写入代码并推送 GitHub。
  • 对所有 4xx/5xx 无限重试，造成费用和负载问题。
  • 只判断 status=200，不验证 JSON schema。
  • 日志打印完整请求头，泄漏 Authorization。
  • 混淆网络错误、API 错误和模型内容质量问题。
