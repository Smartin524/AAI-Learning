## 2. 数据类型

- [ ] **结构化与非结构化数据。** 能区分表格数据与文本、图像、视频、音频。
- [ ] **数值与类别数据。** 能区分数值、无序类别和有序类别。
- [ ] **时间序列数据。** 理解时间顺序、趋势和季节性的重要性。
- [ ] **网络数据。** 能指出 node（节点）、edge（边）及其属性。
- [ ] **非结构化数据的挑战。** 理解高维度，以及文本、视频、音频中的上下文或时间依赖。

## 3. EDA 与 Data Profiling

- [ ] **EDA 的目的。** 理解分布、模式和关系，检查数据质量与假设；区分这些目标与模型优化。
- [ ] **Profiling 与 Cleaning 的区别。** 前者发现问题，后者处理问题。
- [ ] **Structure discovery：结构发现。** 检查字段类型、数据格式和唯一性；知道重名不一定是重复记录。
- [ ] **Content discovery：内容发现。** 检查缺失值、取值范围、分布和无效数值。
- [ ] **Relationship discovery：关系发现。** 检查变量之间的关联；知道相关不等于因果。
- [ ] **常见 pandas 操作。** 理解 `info()`、`describe()`、`isnull().sum()`、`nunique()`、`min()`、`max()` 和 `corr()` 的用途。

## 4. Data Cleaning

- [ ] **识别数据质量问题。** 能找出缺失、重复、无效值和格式不一致。
- [ ] **缺失不等于零。** 能解释为什么 GPS 缺失不代表球员没有跑动。
- [ ] **删除缺失数据。** 能说明什么时候可以考虑删除，以及数据损失和偏差风险。
- [ ] **Mean / Median / Mode 填补。** 能根据数值分布、异常值和类别数据选择方法。
- [ ] **重复记录判断。** 根据记录含义和关键字段判断，避免仅凭同名删除。
- [ ] **无效值与格式修正。** 能处理负年龄、单位不同、类别拼写不一致等问题。
- [ ] **防止数据泄漏。** 先划分训练与测试数据，再用训练集计算填补值；验证和测试使用相同规则。

## 5. 异常值检测

- [ ] **异常值不一定是错误。** 先检查来源和业务含义，再决定保留、修正或删除。
- [ ] **Z-score 原理与条件。** 知道它衡量离均值多少个标准差，常用于近似正态数据，也会受极端值影响。
- [ ] **Z-score 简单计算。** 会用 `z = (x - mean) / std`，理解课件中的 `|z| > 3` 判定规则。
- [ ] **IQR 原理与条件。** 理解 Q1、Q3 和 IQR，知道它比均值与标准差对极端值更稳健。
- [ ] **IQR 简单计算。** 会计算 `IQR = Q3 - Q1`，以及 `Q1 - 1.5 × IQR`、`Q3 + 1.5 × IQR` 两个边界。
- [ ] **Isolation Forest。** 理解异常点通常更容易被随机切分隔离，路径更短。
- [ ] **LOF。** 理解它比较一个点与邻居的局部密度，识别局部异常。
- [ ] **DBSCAN。** 理解密度聚类与噪声点的基本概念。
- [ ] **方法选择综合题。** 能根据近似正态、偏态、局部密度等特点选择方法，并解释限制。
