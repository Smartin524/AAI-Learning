01 · 变量、基本类型与 Casting

知道数据是什么类型，以及如何安全转换类型。

Casting：类型转换

Casting 是把一种类型转换成另一种类型，常用 int()、float()、str()、bool()。

age = int("20")
height = float("1.75")
message = "明年我 " + str(age + 1) + " 岁"

try:
    top_k = int(input("请输入检索数量："))
except ValueError:
    print("请输入整数，例如 3")
常见坑：input() 永远返回字符串；int("3.14") 会报错；bool("False") 是 True，因为非空字符串都是真值。

  2. 输入身高并转换成 float。
  3. 比较 bool(0)、bool("") 和 bool("False")。

def chunk_text(text, size=10):
    """把长文本按固定字符数切块。"""
    return [text[i:i + size] for i in range(0, len(text), size)]

10 · 迷你 RAG 检索器

把容器、函数、向量与排序串起来。

import numpy as np

documents = [
    {"text": "RAG 会先检索资料。", "vector": np.array([0.9, 0.2])},
    {"text": "list 是可修改容器。", "vector": np.array([0.2, 0.9])}
]
question_vector = np.array([1.0, 0.1])

def cosine(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

for doc in documents:
    doc["score"] = cosine(question_vector, doc["vector"])

best = max(documents, key=lambda doc: doc["score"])
print(best["text"])
综合练习
  1. 扩展到 5 条文档。
  2. 返回最高的 3 条并拼成 context。
