Data encoding｜六种编码怎么选

本章图表 / 方法：六类编码与 10 件商品表（第 2–12、18–20 页）。

一句话：大多数模型只接受数字，所以要把类别变成数字。选方法只看两件事：① 类别有没有顺序（ordinal / nominal）② 类别有多少个（cardinality）。

编码适用怎么转优点缺点
Label / Ordinal有顺序Size：Small = 1，Medium = 2，Large = 3简单、省内存、保留顺序；树模型 / XGBoost 用得很好用在无序变量上，模型会误以为有顺序和线性关系
One-Hot无序、类别少Color 5 类 → Color_Black、Color_Blue… 5 列 0/1不制造假顺序，最清楚；适合线性模型（Logistic、SVM）和距离模型（KNN）类别多时维度爆炸；dummy variable trap（一列能由其他列推出 → 多重共线性）
Count / Frequency无序、类别多Silver 出现 3 次 → count = 3，frequency = 0.3不增加维度；体现常见 / 罕见；新类别可设为 0频数相同的类别无法区分（Silver 和 Black 都是 0.3）
Binary无序、中高基数先编号 1–6，再写成二进制：Dell = 001，Lenovo = 010… 6 类只要 3 列省内存；不假设线性顺序；每个类别唯一，没有碰撞列没有直观含义；仍引入人工的数值关系；不适合简单线性模型
Target无序、高基数每类替换为该类目标的均值利用和目标的关系，树模型（LightGBM、CatBoost、XGBoost）很强过拟合 / 数据泄漏；样本少的类别不稳定
Hash无序、极高基数（如 NLP 词表）index = hash(类别) mod K，固定 K 列维度固定、非常省内存hash collision：不同类别可能落到同一列

Target encoding & Regularization｜目标编码与平滑

本章图表 / 方法：Category 目标均值、三种正则化、Bayesian 平滑计算、sigmoid 权重（第 13–17、21 页）。

公式：Enc(i) = Mean(Target | Category = i)。目标是 0/1 时就是该类的正例比例；目标是连续值（如价格）时就是该类的平均值。

CategoryID价格n总和目标编码
Premium1, 3, 5, 9, 101200, 900, 1100, 1250, 850553001060
Budget2, 6, 8300, 500, 32031120373.33
Standard4, 7400, 4502850425

两个问题：① 过拟合 / 泄漏：只出现一两次的类别，编码值就等于它自己的目标值，模型等于偷看了答案。② 对噪声敏感：出现 1 次和出现 1000 次的类别被同样信任。

三种正则化

方法做法
Smoothing把类别均值和全局均值加权平均，小样本类别被拉向全局均值
K-fold / Out-of-fold（金标准）每个样本的编码用其他 K−1 折的均值计算，样本自己的目标永远不参与自己的编码
Adding random noise给编码值加一点高斯噪声，打破完美对应，让模型学大趋势

平滑公式与计算

Smoothed = (n × 类别均值 + m × 全局均值) / (n + m)
n = 该类别的样本数（证据），m = prior / 平滑参数（伪样本数）

全局均值 = 7270 / 10 = 727，取 m = 3：

Categoryn原均值计算平滑后被拉多少
Premium51060(5×1060 + 3×727) / 8935.12下拉 124.88（样本多，拉得少）
Budget3373.33(3×373.33 + 3×727) / 6550.17上拉 176.84（n = m，各占一半）
Standard2425(2×425 + 3×727) / 5606.2上拉 181.2（样本最少，拉得最多）

第 21 页补充：category_encoders 库用的是 sigmoid 权重：样本数过了某个阈值，几乎完全相信类别均值；样本太少则几乎忽略它。上面的线性公式则是按 m 以固定速度往全局均值拉。

from sklearn.preprocessing import TargetEncoder
encoder = TargetEncoder(target_type="continuous", smooth=3, cv=5)
X_train_enc = encoder.fit_transform(X_train, y_train)   # 内部用 K 折交叉拟合，防泄漏
X_test_enc  = encoder.transform(X_test)                 # 测试集用训练集学到的映射

易错：训练集要用 fit_transform（带交叉拟合），不能写成 fit(X, y).transform(X)，后者会让每个样本用到自己的目标值。

Data / Feature scaling｜四种 scaler

本章图表 / 方法：缩放目的、四种 scaler 对照表、散点对比图、房产税例子（第 22–25 页）。

一句话：缩放只改变数值的范围和大小，不改变分布形状。目的有两个：让各特征在距离计算中贡献均衡（KNN、SVM），以及让梯度下降收敛更快。

Scaler公式最适合对异常值输出范围保留 0 吗
StandardScaler(x − μ) / σ正态分布；默认选择；线性模型、SVM、PCA敏感通常 −3 到 3（无硬性上下限）否
MinMaxScaler(x − min) / (max − min)非正态、有已知边界（如像素）；神经网络、图像最敏感：一个异常值把其他数据挤到接近 0正好 0 到 1否（除非最小值就是 0）
RobustScaler(x − 中位数) / IQR异常值多或严重偏态不敏感不固定，主体居中否
MaxAbsScalerx / max(|x|)稀疏数据（大部分为 0）、文本 / NLP敏感：最大值决定尺度−1 到 1是

房产税例子（第 25 页）：有一套房子税额 $50k，远高于其他房子。这种“脏”数据用 RobustScaler，因为它用中位数和 IQR，异常值拉不动尺度。

from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler, MaxAbsScaler
scaler = RobustScaler()
X_train_s = scaler.fit_transform(X_train)   # 中位数和 IQR 只从训练集学
X_test_s  = scaler.transform(X_test)

易错：树模型按阈值分裂，通常不需要缩放。缩放也不能把偏态变成正态，那是下一节 power transform 的工作。

Power transformation｜矫正偏态

本章图表 / 方法：为什么要变换、三种偏态、Box-Cox 与 Yeo-Johnson、变换前后直方图（第 26–29 页；power_transform_demo.ipynb）。

一句话：把偏态数据变得尽量接近正态（钟形）。和缩放不同，它会改变分布形状。

为什么需要（第 26 页）：线性回归、逻辑回归、LDA、高斯朴素贝叶斯等参数模型在严重偏态数据上表现差，原因有三：

  • 违反假设：这些模型假设误差或特征近似正态。
  • 对大值敏感：长尾里的少数大值像异常值一样，把模型拉离大多数数据。
  • Heteroscedasticity（异方差）：噪声大小不恒定。幂变换能稳定方差，让大值和小值被同等对待。
偏态样子怎么修例子
正偏 / 右偏长尾在右，大部分数据在左取对数或开方家庭收入、房价、二手车里程
负偏 / 左偏长尾在左，大部分数据在右取幂（平方 / 立方）退休年龄、考试分数（大多数人及格）
零偏 / 对称钟形不用修身高、标准化产品重量
变换能处理的值说明
Logx > 0（log1p 可处理 0）最常用的右偏修正
Box-Cox只能是正数自动拟合 λ；例如 Twitter 粉丝数（对数正态分布）
Yeo-Johnson正数、零、负数都行数据里有 0 或负值时用它

什么时候用：强右偏、方差不恒定、重尾分布、线性模型因非正态表现差。受益的模型：线性回归、逻辑回归、KNN、距离类模型。

from sklearn.preprocessing import PowerTransformer
pt = PowerTransformer(method="yeo-johnson")   # 有 0 或负数；全正数可用 "box-cox"
X_train_t = pt.fit_transform(X_train)         # 默认 standardize=True，变换后顺便标准化
print(pt.lambdas_)                            # 每列学到的 λ

Notebook 例子：House Prices 的 TotalBsmtSF 有很多 0（没有地下室），不能直接用 Box-Cox。可以用 Yeo-Johnson，或者加一列 HasBsmt 标记，只对正值部分做 Box-Cox。

Bias, Fairness & Generalization｜四类偏差和它们的后果

本章图表 / 方法：四类偏差、对公平的影响、对泛化的影响、减少偏差的做法（第 31–34 页）。

偏差含义课件例子
Historical bias数据反映了过去的不平等过去招聘偏向男性 → 模型认为男性更好
Sampling bias某些群体代表性不足人脸数据大多是浅肤色 → 深肤色识别差
Label bias标签本身不公平或有人为错误贷款违约标签来自有偏的审批系统
Measurement bias不同群体的测量方式不同医疗设备对某类人群更准

对公平的后果

  • 误差率不均：信用评分模型对 A 组误判 20%，对 B 组只误判 5%。
  • 自动决策中的歧视：招聘、贷款、保险定价、警务。
  • 失去信任、伦理问题；法律合规风险（如 GDPR 要求平等对待受保护群体）。

对泛化的后果

问题例子
对主导群体过拟合主要用成人数据训练的诊断模型，用在儿童身上失效
学到捷径（poor feature learning）靠背景里的雪来区分狼和狗，换张图就错
Domain shift只在晴天训练的自动驾驶，雨天或夜间失效
不现实的假设（algorithmic bias）用线性模型拟合非线性关系

公平性指标（按群体分开算，再比较）

指标公式回答什么
FPRFP / (FP + TN)真实为负的人里，被误判为正的比例
FNRFN / (FN + TP)真实为正的人里，被漏掉的比例
Demographic parity比较各组 P(预测为正)各组获得有利结果的比例是否接近（不看真实标签）

减少偏差的做法（第 34 页）：提高数据多样性；平衡采样与重加权；公平的标注；公平感知算法；跨群体评估（FPR、FNR、demographic parity）；定期审计；高风险决策加入人工复核。

Bias mitigation techniques｜重加权、过采样、SMOTE 家族

本章图表 / 方法：预处理阶段的偏差缓解：Reweighing、Oversampling、SMOTE、ADASYN、SMOTE-ENN（第 35–37 页；Bias_mitigation_SMOTE_updated.ipynb）。

这些都是 pre-processing 方法：在数据进入模型之前修改训练数据。

方法做法优点缺点
Reweighing给代表性不足、且得到不利结果的群体更高权重，给过度代表的样本更低权重与模型无关；简单不改特征，与受保护属性相关的代理特征（proxy bias）仍存在；可能对加权群体过拟合
Oversampling复制或合成少数群体 / 不利结果的样本，直到比例平衡实现 statistical / demographic parity单纯复制会过拟合
SMOTE取两个相近的少数类点，在它们的连线上生成新点比复制泛化更好；模型不再忽略少数类少数类点靠近多数类边界时会制造噪声；合成点不一定真实
ADASYN给难学的（被多数类包围的）少数类点生成更多样本，容易的少生成集中在决策边界，边界更准对噪声 / 异常值敏感；可能增加类别重叠
SMOTE-ENN两步：先 SMOTE 过采样，再用 ENN（Edited Nearest Neighbours）删除两类中的噪声和重叠点边界更清晰会删掉原始数据（包括多数类）；实现更复杂

易错：重采样只能用在训练集上，先划分再重采样；测试集保持原始分布，否则指标不代表真实情况。

Notebook：SMOTE 在违约数据上的效果

5000 个借款人，违约只占 5%；分层划分 3500 训练 / 1500 测试（测试集里 83 个违约）。SMOTE 后训练集变成 3305 : 3305，测试集保持不变。

  • 不处理：准确率 0.95 很好看，但 83 个违约只抓到 17 个（第四周叫 accuracy paradox）。
  • SMOTE 之后：recall 从 0.20 升到 0.83，但误报从 4 个涨到 212 个，所以准确率下降。原因是合成点越过了边界，边界附近的正常客户被判成违约概率更高。
  • 调高阈值：0.5 → 0.7 让误报减少，recall 降一些，F1 从 0.38 升到 0.50。阈值要按业务目标选（Notebook 扫描了 0.40–0.90）。
  • Borderline-SMOTE 对逻辑回归帮助不大，因为数据本来就不是线性可分的；换成树模型能学非线性边界，F1 更好。

自测

本章图表 / 方法：按考试常见题型整理，先自己答再展开。

1. 教育程度（小学 < 中学 < 大学）用什么编码？城市（50 个）呢？颜色（4 种）呢？

教育程度有顺序 → ordinal；50 个城市无序且类别多 → frequency、binary 或 target；4 种颜色无序且类别少 → one-hot。

2. One-hot 的两个主要缺点？

类别多时维度爆炸（高维、稀疏）；dummy variable trap：一列可由其他列推出，造成多重共线性。

3. 10 行数据中 Gray 出现 2 次，frequency 编码是多少？frequency 编码的缺点？

0.2。频数相同的类别会得到相同的值（碰撞），模型无法区分。

4. 20 个类别用 binary 编码需要几列？

2⁴ = 16 < 20 ≤ 32 = 2⁵，需要 5 列。One-hot 则需要 20 列。

5. 某类别 n = 2、均值 500，全局均值 800，m = 3，平滑后是多少？

(2 × 500 + 3 × 800) / 5 = 3400 / 5 = 680。样本少，被拉向全局均值。

6. 目标编码防泄漏的“金标准”是什么？

K-fold out-of-fold 编码：每个样本的编码只用其他折的数据计算，自己的目标值不参与。

7. 数据有很多极端值，用哪个 scaler？TF-IDF 稀疏矩阵呢？神经网络的像素输入呢？

极端值多 → RobustScaler；稀疏矩阵 → MaxAbsScaler（0 仍是 0）；像素 → MinMaxScaler（固定 0–1）。

8. 特征有 0 和负数，严重右偏，用 Box-Cox 还是 Yeo-Johnson？

Yeo-Johnson。Box-Cox 只能处理正数。

9. 考试分数大多数人很高、少数人很低，是什么偏态？怎么修？

负偏（左偏），长尾在左。用平方 / 立方等幂次修正。

10. 人脸识别数据集大多是浅肤色，属于哪类偏差？贷款违约标签来自有偏的审批系统呢？

前者是 sampling bias；后者是 label bias。

11. SMOTE、ADASYN、SMOTE-ENN 的区别？

SMOTE 在相邻少数类点的连线上插值生成新点；ADASYN 在难学（被多数类包围）的区域生成更多点；SMOTE-ENN 先 SMOTE，再用 ENN 清除两类中的噪声和重叠点。

12. Reweighing 最大的局限是什么？

它不修改特征，与受保护属性相关的代理特征仍然可能带来偏差（proxy bias）；也可能对加权的群体过拟合。
