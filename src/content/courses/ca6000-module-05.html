必须掌握的术语

术语考试级理解
Keras构建和训练深度神经网络的高层 Python API，提供预制的 layers、losses、optimizers 与 metrics；默认后端通常是 TensorFlow，也可配置其他后端。优势是代码简洁、原型快。
TensorFlowGoogle 开发的开源机器学习平台，覆盖建模、自动微分、硬件加速和跨平台部署；Keras 负责高层接口，TensorFlow 提供底层执行与生态。
PyTorch最初由 Meta 开发的深度学习框架，以 tensor、动态图自动微分和 nn.Module 为核心；训练步骤通常比 Keras 显式，因此更容易逐步控制与调试。
tensorn 维规则数值数组。标量是 0-D、向量是 1-D、矩阵是 2-D；图像 batch 常为 4-D。tensor 可置于 CPU/GPU，并可记录运算图以自动计算梯度。
neuron先计算线性组合 z = wᵀx + b，再经过激活函数 a = g(z)。权重决定各输入的重要性，bias 平移决策边界，activation 引入非线性。
parameter训练中被优化器更新的可学习数值，主要是 weights 与 biases。与用户设定的 hyperparameter（学习率、batch size、epoch、层宽等）不同。
forward propagation输入依次通过网络各层产生 logits、概率或预测值，并据此计算 loss。
backpropagation应用链式法则计算 loss 对各参数的梯度；PyTorch 的 loss.backward() 和 TensorFlow 自动微分完成该过程。
gradient descent沿 loss 梯度的反方向更新参数：θ ← θ - η∇θL；η 是 learning rate。
epoch / batch / iterationepoch 是完整遍历一次训练集；batch 是一次送入模型的一组样本；iteration/step 是一次参数更新。60,000 样本、batch 32 时每 epoch 约 1,875 steps。
logits输出层激活前的原始分数。PyTorch 的 CrossEntropyLoss 直接接收 logits，并在内部组合 LogSoftmax 与 NLLLoss，训练时不要先手动 softmax。
loss / metricloss 是可微的优化目标，用来反向传播；metric 是给人观察的性能指标，如 accuracy。优化 accuracy 通常不可直接求导，因此训练仍优化 cross-entropy。
ANN / FCNN / DenseArtificial/Fully Connected Neural Network：相邻层每个神经元全连接；Keras 中由 Dense 表示。图像必须先 flatten，空间邻接结构因此丢失。
CNNConvolutional Neural Network：以局部 filter/kernel 提取共享空间特征，再经 activation、pooling、flatten/Dense 分类，对平移和局部模式更友好。
feature map卷积核在输入上滑动并做点积后产生的二维响应图；一个 filter 产生一张 feature map，多个 filters 产生多个输出通道。
pooling对局部窗口做最大值或平均值聚合以降低空间尺寸、计算量和小范围位移敏感度；没有可学习权重，但可能丢失细节。
dropout训练时随机把一部分激活置零以降低共适应和过拟合；评价/推理时关闭并使用全部单元，因此 PyTorch 必须正确切换 train()/eval()。
inference训练结束后对新样本预测。推理不更新参数，应使用与训练完全一致的形状、dtype、归一化和类别映射。
state_dictPyTorch 中层名到参数 tensor 的映射。保存 state_dict 通常比保存整个模型更可移植，但加载前必须先实例化相同结构。

2. 神经元到底计算什么

对一个神经元，先求加权和：

z = w1*x1 + w2*x2 + ... + wn*xn + b
a = activation(z)

如果每一层都只有线性变换，多层线性函数复合仍然只是一个线性函数，网络无法学习 XOR、曲线边界或复杂图像模式。因此隐藏层必须加入非线性 activation。

激活形式 / 输出常见位置与注意点
ReLUmax(0, z)隐藏层常用；计算快、缓解饱和，但负区间梯度为 0，可能出现 dying ReLU。
Sigmoid1 / (1 + e^-z)，输出 0–1二分类单输出概率；大正/负值处梯度很小，不常作为深层隐藏激活。
Softmax把 K 个 logits 归一为总和 1 的概率分布互斥多分类输出层，如 MNIST 10 类；预测类别通常是 argmax。
Softpluslog(1 + e^z)ReLU 的平滑替代，输出始终为正；不是 MNIST 多分类输出的首选。

3. MNIST 数据与预处理

MNIST 有 70,000 张 28×28 灰度手写数字图：60,000 training、10,000 test，label 为 0–9。原始像素为 0–255。监督学习中图像是 feature，数字标签是 target。

import tensorflow as tf
from tensorflow import keras
import numpy as np

(X_train, y_train), (X_test, y_test) = keras.datasets.mnist.load_data()

print(X_train.shape)  # (60000, 28, 28)
print(X_test.shape)   # (10000, 28, 28)
print(y_train.shape)  # (60000,)

# 必须让 train 与 test 使用相同转换
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0

为什么除以 255：将输入缩放到 0–1，令梯度优化数值更稳定。不能只归一化训练集却用 0–255 的测试集；也不能把 y 除以 255，因为 label 是类别编号。

4. FCNN：Flatten 后进行全连接分类

ann = keras.Sequential([
    keras.layers.Input(shape=(28, 28)),
    keras.layers.Flatten(),
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dense(10, activation="softmax"),
])

ann.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

history = ann.fit(
    X_train, y_train,
    epochs=10,
    validation_split=0.2,
    batch_size=32,
)
test_loss, test_accuracy = ann.evaluate(X_test, y_test)

sparse_categorical_crossentropy 用于整数类别标签（0–9）；若标签已 one-hot 编码才使用 categorical_crossentropy。Adam 是 optimizer；accuracy 只是观察指标。

5. Dense 参数量是高频计算题

Dense 层参数量：

parameters = input_units * output_units + output_units
             weights                       biases
结构参数量说明
784 → 10784×10 + 10 = 7,850无隐藏层；每个输出节点连接所有 784 个像素，并有一个 bias。
784 → 128784×128 + 128 = 100,480隐藏 Dense 层。
128 → 10128×10 + 10 = 1,290Softmax 输出层。
总计101,770加入 128 隐藏单元后表达能力更强，但计算量和过拟合风险也增加。

7. 为什么 FCNN 不适合高分辨率图像

FCNN 把图像 flatten 后有三个核心限制：

  • 参数爆炸：1920×1080 RGB 图像有 6,220,800 个输入；只连接 128 个隐藏单元就超过 7.96 亿个 weights。
  • 空间关系丢失：flatten 后模型不知道相邻像素原本在同一局部区域。
  • 位移敏感：同一笔画轻微平移会落在完全不同的输入节点，模型需重新学习。

8. CNN 的完整特征提取链

Convolution → ReLU → Pooling →（重复）→ Flatten → Dense → Softmax。浅层 filters 学边缘和线条，深层组合为纹理、形状和对象部件；weight sharing 让同一 filter 能在整张图寻找相同模式。

无 dilation 时，单个空间维度的卷积输出为：

output = floor((input - kernel + 2*padding) / stride) + 1

MNIST 输入 28×28×1，3×3 kernel、stride 1、padding="valid" 后变为 26×26；再做 2×2 max pooling、stride 2 后变为 13×13。

10. 如何读 training / validation loss

  • 两者都下降且接近：模型仍在学习，泛化通常正常。
  • training loss 继续下降而 validation loss 开始上升：典型 overfitting，应考虑 early stopping、dropout、正则化、数据增强或简化模型。
  • 两者都高且下降缓慢：可能 underfitting、学习率不当、模型太小、数据/标签问题。
  • 曲线剧烈震荡：学习率可能过高、batch 太小或数据尺度/实现存在问题。

import torch

x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
print(x.shape)   # torch.Size([2, 2])
print(x.dtype)   # torch.float32
print(x.device)  # cpu，或移动到 cuda / mps

w = torch.tensor(2.0, requires_grad=True)
y = (w - 3) ** 2
y.backward()
print(w.grad)    # 2 * (w - 3) = -2

requires_grad=True 让 PyTorch 记录与该 tensor 有关的运算图；backward() 根据链式法则把梯度累积到叶子 tensor 的 .grad。梯度是累积的，所以每次训练 step 前必须清零。

3. 用 nn.Module 定义网络

from torch import nn

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.layers = nn.Sequential(
            nn.Linear(28 * 28, 128),
            nn.ReLU(),
            nn.Linear(128, 10),
        )

    def forward(self, x):
        x = self.flatten(x)
        return self.layers(x)  # logits，不在这里手动 softmax

model = NeuralNetwork()

__init__ 声明拥有参数或状态的 layers；forward 定义数据流。不要直接调用 model.forward(x)，应调用 model(x)，这样 hooks、autocast 等框架机制才能工作。

5. 六步训练流程

  1. Data preparation/loading/processing。
  2. Model definition。
  3. Loss function 与 optimizer definition。
  4. Training loop。
  5. Evaluation。
  6. Save / load model。
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(
    model.parameters(), lr=0.1, momentum=0.9
)

def train_one_epoch(loader, model, loss_fn, optimizer, device):
    model.train()
    total_loss = 0.0

    for X, y in loader:
        X, y = X.to(device), y.to(device)

        logits = model(X)                 # 1. forward
        loss = loss_fn(logits, y)         # 2. calculate loss

        optimizer.zero_grad()             # 3. clear old gradients
        loss.backward()                   # 4. backpropagation
        optimizer.step()                  # 5. update parameters

        total_loss += loss.item()

    return total_loss / len(loader)

顺序必须记牢：forward → loss → zero_grad → backward → step。若忘记 zero_grad()，梯度会跨 batches 累加；若把 step() 放在 backward() 前，优化器没有本轮梯度可用。

6. 正确评价模型

def evaluate(loader, model, loss_fn, device):
    model.eval()
    total_loss = 0.0
    correct = 0

    with torch.no_grad():
        for X, y in loader:
            X, y = X.to(device), y.to(device)
            logits = model(X)
            total_loss += loss_fn(logits, y).item()
            correct += (logits.argmax(dim=1) == y).sum().item()

    return total_loss / len(loader), correct / len(loader.dataset)

model.eval() 改变 Dropout/BatchNorm 行为；torch.no_grad() 停止记录梯度以节省内存和时间。两者作用不同，不能互相替代。评价后若继续训练，要再次 model.train()。

8. Topic 14b 的单参数训练说明

课件用一个已经设定大部分 weights/biases、但 final_bias 尚未优化的网络演示训练。只有设为 requires_grad=True 且交给 optimizer 的参数才会更新。训练的本质不是“模型自己知道答案”，而是：

  1. 固定输入与 labels，forward 得到预测。
  2. loss 衡量预测和标签的差距。
  3. autograd 求 ∂loss/∂final_bias。
  4. SGD 以学习率 0.1 沿负梯度更新 bias。
  5. 重复迭代直到 loss 降低，再画 prediction curve 验证。

9. CIFAR10 finger exercise 的关键修改

CIFAR10 是 32×32 RGB 图像，单样本形状 (3, 32, 32)，类别为 airplane、automobile、bird、cat、deer、dog、frog、horse、ship、truck。若把图像送入 Linear 网络，输入特征数为 3×32×32 = 3,072。

self.flatten = nn.Flatten(start_dim=1)
self.fc = nn.Linear(3 * 32 * 32, 10)

课件纠错：课件最后一页写 nn.Flatten(start_dim=0)，但 batched 输入的第 0 维是 batch；训练时通常必须用 start_dim=1 保留 batch 维。设为 0 会把整个 batch 也压成一维，导致形状不匹配。

错误后果正确做法

忘记 optimizer.zero_grad()旧梯度累积，更新方向和大小错误。每个 batch 在 backward 前清梯度。
评价时忘记 eval()Dropout 仍随机丢弃，BatchNorm 仍用 batch statistics。model.eval() + torch.no_grad()。
Flatten 抹掉 batch 维Linear 接收错误的一维总向量。PyTorch batched data 使用 start_dim=1。
把 epoch 当 batch 数无法解释日志中的 1,875 steps。steps ≈ ceil(samples / batch_size)。
只看 training accuracy无法发现 overfitting，也不能说明泛化。监控 validation curve，最后只用 test 做一次客观评价。
保存 state_dict 后直接预测字典不是模型，不能被调用。实例化相同 class → load_state_dict → eval。
混淆 output probability 与 label拿长度 10 的向量与整数标签直接比较。用 argmax 转为类别索引。

考试题型与答题模板

题型 1：解释为什么 CNN 比 FCNN 更适合图像

标准答案结构：FCNN flatten 破坏空间关系且参数量随分辨率快速增长；CNN 用局部感受野和共享 filters 提取位置可复用的边缘/纹理/形状，pooling 降采样并提高小位移鲁棒性，最后才用 Dense 分类。因此 CNN 更可扩展并更符合图像的空间结构。

题型 2：写 PyTorch 训练 loop

至少写对 model.train()、遍历 DataLoader、forward、loss、zero_grad、backward、step。若题目还问 test，要补 eval()、no_grad() 与 accuracy 计算。

题型 3：参数量和形状

  • Dense：in × out + out。
  • Conv2D：(kernel_h × kernel_w × in_channels + 1 bias) × filters。
  • 卷积空间尺寸：floor((N-K+2P)/S)+1。
  • MaxPool 没有可学习参数，但改变 height/width。
  • Flatten 的特征数等于剩余所有非 batch 维度的乘积。

题型 4：诊断训练曲线

先比较 train 与 validation 的方向和差距，再判断 underfitting/overfitting/optimization instability，最后给对应措施。不要只说“loss 越低越好”；validation 上升是关键信号。
