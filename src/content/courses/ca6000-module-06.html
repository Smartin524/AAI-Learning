必须掌握的术语

术语用这周例子理解
sequence / time series有顺序的数据。每天一个收盘价组成时间序列；改变排列顺序，就改变了历史走势。
RNNRecurrent Neural Network，循环神经网络。同一套计算规则反复用于每个时间步，并把状态传到下一步。
hidden state到当前时间步为止的可学习历史摘要，通常写作 ht；课件用 Vt。它是运行时计算的数值，不是保存所有历史的数据库。
timestep / featuretimestep 是序列中的位置，如第 3 天；feature 是该位置的观测维度，如收盘价、成交量。5 天、每天 2 个指标，对应 (5, 2)。
sample / batch一个 sample 是一整段输入序列及其目标；batch 是一次一起处理的若干个 samples。4 段各 5 天的序列，不是“4 个时间步”。
unit / layerunits 是每个时间步 hidden state 的宽度；layer 是堆叠的循环层数。一个 SimpleRNN(16) 是一层、状态宽度 16，不是 16 层。
unroll / parameter sharing展开图把每个时间步画出来；各步复用同一组权重。横向画出 9 个 cell，不代表建立了 9 套独立参数。
many-to-one / many-to-many一段输入对应一个输出，或对应一段输出。本课分别演示“9 天 → 第 10 天”和“每一天 → 下一天”。
BPTTBackpropagation Through Time，把循环按时间展开后，用链式法则让 loss 沿时间依赖向前追溯，求出共享参数的梯度。
LSTM / GRU带门控机制的 RNN 变体，用来改善长期依赖学习。课件引入 LSTM 的 carry state，GRU 仅被列为另一种改进架构。

Topic 15 · RNN Architecture 与 Time Steps

对应课件第 2–5、7 页。

1. 为什么需要“记住前面”？

假设今天温度都是 30°C，一种情况是过去几天从 25°C 持续上升，另一种是从 35°C 持续下降。只看今天的单个数值，模型不知道来路。RNN 每读取一天，就把“今天的观测”与“昨天留下的摘要”合并，使当前输出能依赖前面的顺序。

课件列出时间序列预测与异常检测、自然语言处理、语音识别、图像描述等应用。共同点是需要处理序列关系。普通全连接网络也可以使用人为拼接的历史窗口；RNN 的特点是沿时间递推，并共享参数。

2. 一个 cell 每一步接收什么？

  1. 当前输入 xt：今天的收盘价，或今天的多个指标。
  2. 上一步状态 ht−1：模型对前面历史的摘要。
  3. 两者经过带权重的组合和非线性激活，得到新的 ht。
  4. ht 既能传向下一时间步，也能供输出层计算预测。
初始状态 h₀ → [读取 x₁，得到 h₁] → [读取 x₂，得到 h₂] → … → hₜ
                                                                       ↓
                                                             输出层 → 预测值

像读一句话：每读一个词，就更新一次对前文的理解。状态会随输入改变；权重是在训练时学习的规则。推理时也会更新状态，但通常不更新权重。

3. 公式中的每一项各做什么？

hₜ = tanh(Wₓ xₜ + Wₕ hₜ₋₁ + bₕ)
ŷₜ = g(Wᵧ hₜ + bᵧ)

这里用列向量记法；课件第 7 页采用右乘形式。Wₓ 对应课件 Wax，Wₕ 对应 Waa，负责分别处理当前输入与历史状态；bias 在激活函数内部相加。输出激活 g 取决于任务：课件示例用 tanh，一般无界数值回归可用线性输出。

补充手算：若只有 1 个 feature、1 个 unit，h₀=0，wₓ=1、wₕ=0.5、b=0，输入依次为 0.5 和 0.2，则 h₁=tanh(0.5)≈0.462，h₂=tanh(0.2+0.5×0.462)≈0.406。第二步已经包含第一步的信息，并非只计算 tanh(0.2)。这些权重只为演示，不是课件训练结果。

4. 横向展开、纵向堆叠、状态宽度

看哪个方向表示什么改变后会怎样
横向：9 个时间步同一个 cell 沿序列计算 9 次。序列更长，计算与反传路径更长；固定输入维度和 units 时，参数量不变。
纵向：2 个循环层第一层输出的序列交给第二层。增加模型深度，并新增一套层参数。
每个 cell 内：16 units每一步状态是长度 16 的向量。增加状态表示容量，也增加参数量。

补充参数量：Keras SimpleRNN 的输入特征数为 F、units 为 U，使用 bias 时共有 F×U + U×U + U 个参数。课件 F=1、U=1 时为 3 个；再接 Dense(1) 增加 2 个，合计 5 个。把 5 天改为 9 天，仍是这 5 个参数。

Topic 15 · Features、Input Shape 与滑动窗口

对应课件第 6、8–10、12 页，以及 Notebook 的数据准备。

1. 三维输入：(samples, timesteps, features)

整份输入数组的第 0 维是样本总数；训练时取出一个 batch 后，该维就是这一批的样本数 B。Keras 每批 RNN 输入形状为 (B, T, F)。Input(shape=(T, F)) 描述单个样本，不把 batch 维写进去。

形状实际含义
(1, 9, 1)1 段序列，连续 9 天，每天只有收盘价。
(4, 5, 1)4 段序列，每段连续 5 天，每天只有收盘价。
(32, 5, 3)一批 32 段序列，每段 5 天，每天有 3 个指标。

多特征时，模型在一个时间步同时看到当天所有指标。不要把“同一天的 3 个指标”当成“连续 3 天”。reshape 只重排形状，不会自动为你构造滑动窗口。

2. 课件的 10 天数据与缩放

原始数值：9, 7, 6, 10, 8, 7, 11, 9, 6, 12
课件缩放：z = (x − 6) / (12 − 6)
缩放结果：0.5, 1/6, 0, 2/3, 1/3, 1/6, 5/6, 0.5, 0, 1

图中 0.17、0.67 等是展示时四舍五入的值。构造预测输入应切片原数组，保留计算精度，不要手抄图上的近似小数。

缩放边界：课件用全部 10 天的最小值和最大值做教学演示。若宣称第 10 天是未来测试数据，就不能提前用它的最大值 12。实际预测应先按时间划分，再仅用训练期数据拟合缩放参数；未来值缩放后可能超过 1，这本身不是计算错误。

3. “5 天 → 下一天”到底怎样组成 4 个样本？

样本输入窗口目标
1第 1–5 天：[9, 7, 6, 10, 8]第 6 天：7
2第 2–6 天：[7, 6, 10, 8, 7]第 7 天：11
3第 3–7 天：[6, 10, 8, 7, 11]第 8 天：9
4第 4–8 天：[10, 8, 7, 11, 9]第 9 天：6
留待预测第 5–9 天：[8, 7, 11, 9, 6]第 10 天：12

range(5, 9) 只产生 5、6、7、8 四个索引；z[i-5:i] 取之前 5 天，z[i] 是紧接着的一天。相邻窗口会重叠，这是构造方式的结果。对于 N 个数据点、窗口长 T、预测下一点，使用所有合法窗口时共有 N−T 个样本；本例特意留出最后一个窗口，所以训练只有 4 个。

Topic 15 · Many-to-One 与 Keras 实现

对应课件第 8–13 页，以及 Notebook 的两组 many-to-one 实验。

1. 先读完一段历史，再输出一个值

RNN 内部每一步都会计算状态；many-to-one 只把最后一步状态交给输出层。例如 5 天的历史被汇总成 h₅，再映射成第 6 天的预测。“最后一步状态”不等于“最后一天的原始输入”。

输入 (B, 5, 1)
    ↓ SimpleRNN(U)，return_sequences=False
最后状态 (B, U)
    ↓ Dense(1)
预测 (B, 1)

课件第一组把前 9 天作为唯一输入，第 10 天作为训练标签，再对同一个输入调用 predict。因此预测点贴近标签，只能说明模型拟合了这一个样本；第 10 天的答案已经参与训练，不能称为未知数据测试。

2. 代码参考：复现课件的单样本结构

展开完整示例：9 天输入 → 1 个数值 
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, SimpleRNN, Dense
from tensorflow.keras.optimizers import Adam

tf.keras.utils.set_random_seed(3)
values = np.array([9, 7, 6, 10, 8, 7, 11, 9, 6, 12], dtype="float32")
z = (values - values.min()) / (values.max() - values.min())

# 教学拟合：第 10 天会作为训练答案，并非测试集。
X = z[:-1].reshape(1, 9, 1)  # 1 个样本、9 个时间步、1 个特征
Y = z[-1:].reshape(1, 1)    # 与模型输出 (B, 1) 对齐

model = Sequential([
    Input(shape=(9, 1)),
    SimpleRNN(1, activation="tanh"),
    Dense(1, activation="tanh"),  # 保留课件的输出激活
])
model.compile(optimizer=Adam(learning_rate=0.01), loss="mean_squared_error")
history = model.fit(X, Y, epochs=3000, verbose=0)
prediction = model.predict(X, verbose=0)
print(prediction.shape)  # (1, 1)

课件与 Notebook 差异：PDF 示例训练 5000 epochs，Notebook 为 3000；这不是 RNN 的固定要求。上面沿用 Notebook。原稿将标签 reshape 为 (B, 1, 1)，本页明确改为与 many-to-one 输出一致的 (B, 1)，避免依赖框架的隐式维度处理。

3. 代码参考：滑动窗口与留出下一天

下面保留同一串数据和 4 个训练窗口，但修正为仅使用前 9 天的缩放参数，并使用线性回归输出。这与原稿全序列缩放、tanh 输出的数值结果不同，不能拿两次预测值直接当作复现一致性比较。

展开完整示例：4 段历史训练，预测第 10 天 
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, SimpleRNN, Dense
from tensorflow.keras.optimizers import Adam

tf.keras.utils.set_random_seed(3)
values = np.array([9, 7, 6, 10, 8, 7, 11, 9, 6, 12], dtype="float32")
train = values[:9]  # 只使用预测时已经知道的历史
minimum = train.min()
span = train.max() - minimum
if span == 0:
    raise ValueError("训练序列为常数，不能直接使用此 min-max 公式")
z = (train - minimum) / span

window = 5
X = np.array([z[i-window:i] for i in range(window, len(z))], dtype="float32")
X = X.reshape(-1, window, 1)  # (4, 5, 1)
Y = z[window:].reshape(-1, 1)  # (4, 1)，第 6–9 天
X_next = z[-window:].reshape(1, window, 1)  # 第 5–9 天

model = Sequential([
    Input(shape=(window, 1)),
    SimpleRNN(1, activation="tanh"),
    Dense(1),  # 线性输出：未来缩放值可能大于 1
])
model.compile(optimizer=Adam(learning_rate=0.01), loss="mean_squared_error")
history = model.fit(X, Y, epochs=3000, batch_size=4, shuffle=False, verbose=0)
scaled_prediction = model.predict(X_next, verbose=0)[0, 0]
predicted_value = scaled_prediction * span + minimum
print("预测第 10 天：", float(predicted_value))
print("留出真实值：", float(values[9]))
print("上一天数值基线：", float(train[-1]))

只靠 4 个窗口和 1 个留出点，仍无法得出可靠的泛化结论。至少要在更多按时间留出的样本上比较误差，并与“下一天等于上一天”的简单基线比较。训练 3000 次不会创造新的独立数据。

4. 训练日志应该怎么读？

  • MSE：预测与目标之差的平方的平均值；越低表示当前评价数据上的误差越小。
  • batch_size=4：4 个训练窗口一起计算 loss 和梯度，因此本例每 epoch 更新一次参数。
  • epoch：完整遍历训练样本一轮，不是“向未来预测一天”，也不是 hidden cell 数。
  • predict(X)：若 X 是训练窗口，得到的是训练集拟合；预测未训练过的目标需要另构造窗口。
  • 反归一化：预测的是缩放值时，用训练时同一组参数执行 x̂ = ẑ × span + minimum。

Topic 15 · Many-to-Many

对应课件第 14 页。该页给出结构图；新增 Notebook 只实现了 many-to-one，以下形状与代码为配套补充。

课件图中，每读入一天就预测下一天：输入第 1–8 天，目标为第 2–9 天。这叫向前错一位的序列监督。训练后，再读到第 9 天时，才输出对第 10 天的预测。

输入：[第 1 天，第 2 天，…，第 8 天]
目标：[第 2 天，第 3 天，…，第 9 天]

输入 (B, T, F)
    ↓ SimpleRNN(U, return_sequences=True)
全部时间步状态 (B, T, U)
    ↓ 每一步使用同一个 Dense(1)
预测序列 (B, T, 1)

return_sequences=True 保留每一步输出，False 只返回最后一步。它决定“返回哪些结果”，并不会让网络停止在内部计算中间状态。堆叠循环层时，前一层通常需返回序列，供后一层逐步读取。

补充代码：序列到序列的形状检查，无需训练 
import numpy as np
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, SimpleRNN, Dense, TimeDistributed

known = np.array([9, 7, 6, 10, 8, 7, 11, 9, 6], dtype="float32")
z = (known - known.min()) / (known.max() - known.min())
X = z[:-1].reshape(1, 8, 1)  # 第 1–8 天
Y = z[1:].reshape(1, 8, 1)   # 第 2–9 天

model = Sequential([
    Input(shape=(None, 1)),  # 接受不同长度的序列
    SimpleRNN(4, return_sequences=True),
    TimeDistributed(Dense(1)),
])
assert tuple(model(X).shape) == Y.shape  # (1, 8, 1)

上面只验证结构，随机初始化后的输出没有预测意义。若之后完成训练，可把全部已知 9 天输入同一模型，取最后一个输出预测第 10 天。只把第 9 天孤立输入默认无状态模型，不会自动继承先前调用的历史。

别混淆：此处每个输出预测的是紧接当前输入的下一天，不是一次自动得到未来连续 8 天。多步未来预测需要另外设计目标，或逐步把预测喂回模型，后者会累积误差。

Topic 15 · SimpleRNN 局限与 LSTM Carry State

对应课件第 15–16 页；以下用标准符号补充解释门控机制。

1. 为什么长序列难学？

训练要追溯“早期状态对最终 loss 的影响”。BPTT 的梯度沿时间反复乘上状态变换的导数：有效因子持续小于 1 时，早期梯度可能很小，远处信息难以学到；持续放大时，梯度可能爆炸，更新不稳定。

课件用 Waa 很小或很大帮助建立直觉；严格说还涉及权重矩阵、激活函数导数和时间长度，不能只用某一个权重是否大于 1 判定。尤其 tanh 状态本身受限于 (−1, 1)，梯度爆炸不等于 tanh 状态无限增大。

补充：梯度裁剪可以限制过大的梯度，但不能自动恢复已经消失的远程信号；LSTM/GRU 则改变了信息保留和更新的结构。

2. LSTM 多出的 carry state 做什么？

SimpleRNN 主要依赖 ht 传递信息。LSTM 增加 cell state，也叫 carry state，记为 ct，并用学习到的门决定保留什么、写入什么、输出什么。可以把 c 看作持续修改的记事本，h 看作当前对外提供的摘要；这个比喻不表示它能永久、完整地保存历史。

部分作用
forget gate ft决定旧 cell state 各维保留多少。
input gate it 与 candidate c̃t生成候选信息，并决定写入多少。
output gate ot决定当前 cell state 的哪些部分用于产生 hidden state。
cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ
hₜ = oₜ ⊙ tanh(cₜ)

⊙ 是逐元素相乘。门通常使用 sigmoid 产生 0–1 的控制量。旧记忆有了受门控制的加法传递路径，因而更容易保留长期信息，但不是彻底消除梯度问题。课件只点名 GRU；本页不把 GRU 的完整门公式列为本周课件已展开的知识。

Notebook 复盘：常见错误与修正

容易错在哪里正确理解或修正
9 timesteps 就是 9 layers它是一层循环结构运行 9 步，参数共享。units 是状态宽度，又是另一个维度。
many-to-one 标签写成 (B, 1, 1)SimpleRNN 默认接 Dense(1) 输出 (B, 1)，标签也明确采用 (B, 1)。many-to-many 才按序列对齐 (B, T, 1)。
直接复制 PDF 的 Input 语句PDF 第 11、13 页有括号和排版问题；有效写法为 Input(shape=(5, 1))，使用普通英文引号和 # 注释。
tanh 输出能预测任意数值它受限于 (−1, 1)，不能精确达到 1，也无法表示大于 1 的缩放目标；一般无界回归可用 Dense(1) 的默认线性输出。
未知第 10 天参与 min/max即使它没有作为训练标签，也泄漏了未来分布信息。先按时间划分，再在训练期拟合缩放参数。
用 [0.33, 0.17, …] 手写测试窗口切片同一套缩放后的历史数组，避免四舍五入和日期对齐错误。
random.seed(3) 固定所有训练随机性它只设置 Python 的随机源；TensorFlow 示例使用 tf.keras.utils.set_random_seed(3)。跨硬件/版本仍不保证完全相同。
把整条时间轴打乱后造窗口每个窗口内部必须保持时间顺序。已构造的独立窗口在无状态训练中可以重排；训练/验证/测试目标仍需按时间合理划分。
predict 自动记住上一次调用默认非 stateful RNN 不跨调用保存该历史；需输入完整窗口，或显式设计状态传递。
loss 很低代表未来预测准确先确认 loss 属于训练还是留出数据，再比较时间留出误差与简单基线。

自测与答题模板

1. 形状：32 个样本，每个 7 天，每天 3 个指标，16 units

查看答案

输入为 (32, 7, 3)，Input(shape=(7, 3))。SimpleRNN(16) 默认输出 (32, 16)，接 Dense(1) 得到 (32, 1)；return_sequences=True 时循环层输出 (32, 7, 16)，逐步映射后为 (32, 7, 1)。循环层参数为 3×16+16×16+16=320；单输出 Dense 再加 17，总计 337。

2. 为什么 range(5, 9) 只有 4 个训练样本？

查看答案

右端点不包含，i 为 5、6、7、8。各输入窗口取 i 前面的 5 个值，对应第 6–9 天的目标；第 10 天没有作为这四个窗口的训练标签。若改为 range(5, 10)，则新增第 10 天为训练目标，不能再用它作为原来的留出测试点。

3. 4 个窗口、batch_size=4、3000 epochs，更新多少次？

查看答案

在本例普通 fit 流程中，每 epoch 有 ceil(4/4)=1 个 batch，共 3000 次参数更新。5 个时间步是每个序列内部的递推过程，不额外乘到更新次数上。

4. 单样本实验预测第 10 天很准，能说明什么？

查看答案

第 10 天已经作为监督标签参与训练，预测使用的输入又是训练输入，所以这是样本内拟合。要检验泛化，需使用训练时未见过的后续目标，并避免缩放参数泄漏未来信息。

5. 用三句话解释 RNN 与 LSTM

查看答案

RNN 在每一步把当前输入和上一步 hidden state 合并，用共享参数建模序列顺序。长序列反向传播时梯度可能消失或爆炸，使远距离依赖难学。LSTM 增加 cell/carry state 和门控机制，控制历史信息的保留、写入与输出，改善长期信息传递。

一分钟掌握标准：能口述“当前输入 + 历史状态 → 新状态”；能画出 5 天窗口与下一天标签；能写对 (B,T,F)、Input(shape=(T,F)) 与 (B,1)；能区分 timestep、unit、layer；能解释 return_sequences、训练拟合、未来数据泄漏和 LSTM carry state。
