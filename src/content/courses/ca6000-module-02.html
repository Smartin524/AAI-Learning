必须掌握的术语

术语准确理解

import / aliasimport 引入其他模块；as 在当前作用域给导入名取局部别名。

核心知识

Topic 4 · Modules and Packages｜把代码拆成可复用单元

本章代码 / 工具：标准库 time、random、re；自定义 module；pip / conda 安装第三方 package。

导入整个模块可保留命名空间，调用来源清楚；只导入名称会更简短，但要避免来源不可追踪。自定义 module 就是含函数或类的 .py 文件；把自测放在 __main__ 条件内，直接运行时测试、被导入时只提供接口。

# greeting.py
def greeting(name):
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(greeting("test"))

# app.py
import greeting
print(greeting.greeting("Nick"))

Topic 6 · File I/O｜让程序可靠读写文件

本章代码 / 格式：open()、read()、readline()、write()；文本模式、CSV 的 reader / DictReader 与 JSON 的 loads()。

使用 w 会清空已有文件，只有明确要覆盖时才使用；日志和增量记录优先 a。with 确保文件关闭并刷新缓冲。CSV 的 DictReader 读出的值默认是字符串，后续计算前要显式转换。

from pathlib import Path

path = Path("notes.txt")
with path.open("a", encoding="utf-8") as file:
    file.write("completed topic 6\n")

with path.open("r", encoding="utf-8") as file:
    for line in file:
        print(line.rstrip())

Topic 7 · Error Handling｜把失败路径设计进程序

本章代码 / 工具：try、具体 except、else、finally、assert；time.perf_counter() 与 time.process_time()。

把可能失败的最小操作放进 try；用具体异常给用户可理解的下一步；else 放成功路径，finally 放必须执行的清理。不要用宽泛 except: 把真正的编程错误伪装成已处理。

try:
    number = int(input("Enter a value: "))
except ValueError:
    print("Please enter an integer.")
else:
    print(f"Value is {number}")
finally:
    print("Input attempt completed.")

常见错误

  • 用 from module import * 或过短别名掩盖函数来源。
  • 把自测代码放在模块顶层，导致每次 import 都执行副作用。
  • 无意中用 w 覆盖文件，或未使用 with 而遗漏关闭。
  • 把 CSV 字段全部当作数值，或把 JSON 当作无需验证的可信结构。
  • 捕获所有异常、静默失败，或把 assert 当作正常用户输入处理。
