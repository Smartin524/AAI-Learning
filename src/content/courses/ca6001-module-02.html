Types of ML & What Is Reinforcement Learning?

本章图表 / 方法：监督、无监督与强化学习对照；骑自行车类比（课件第 3–6 页）。

强化学习（RL）研究如何通过与环境交互，学会使预期累计奖励最大的决策策略。每次选择会影响后面的处境，因此不能只看眼前得分。

学习方式给模型什么反馈学会什么
Supervised learning输入及对应标签，例如房屋属性 → 房价从输入预测目标
Unsupervised learning没有目标标签的样本，例如客户消费记录发现分组、结构或表示
Reinforcement learning采取动作后得到的奖励与新状态在不同状态下如何行动，改善长期回报

“RL 不需要 labelled data”指交互式 RL 不要求每一步都有正确动作标签，并不表示不能使用历史轨迹、人类示范或偏好数据。奖励可为正、零或负，也可能延迟出现；“没有奖励”本身也能提供信息。

Reinforcement Learning Implementations and Algorithms

本章图表 / 方法：Value-based、Policy-based、Model-based；Q-learning、SARSA 与 DQN（第 14–15 页）。

方法主要学什么如何选择动作
Value-basedV 或 Q 价值函数根据价值，例如取 argmax Q(s,a)
Policy-based直接学习策略参数由策略输出动作或动作概率；不只限于确定性策略
Model-based使用已知或学习到的状态转移 / 奖励模型预测动作后果，再规划；“model”不是泛指神经网络

学习补充：这是两个分类视角。Value / Policy 关注学什么，Model-based / Model-free 关注是否使用环境模型做规划；它们不是互斥的三选一。

Q-learning 的一次更新

Q(s,a) ← Q(s,a) + α [r + γ max Q(s′,a′) − Q(s,a)]

旧 Q = 2，奖励 r = 1，下一状态最大 Q = 4，α = 0.5，γ = 0.9：目标为 4.6，误差为 2.6，新 Q = 3.3。若下一状态是真正终止状态，未来项为 0，目标只剩即时奖励。

# 学习补充：单次 Q-learning 更新，输入为数值估计
old_q, reward, next_best_q = 2.0, 1.0, 4.0
alpha, gamma, terminated = 0.5, 0.9, False
target = reward + (0.0 if terminated else gamma * next_best_q)
new_q = old_q + alpha * (target - old_q)
print(new_q)  # 3.3
算法更新目标 / 表示关键区别
Q-learningr + γ max Q(s′,a′)Off-policy：实际探索动作与学习目标中的贪心动作可以不同
SARSAr + γ Q(s′,a′实际)On-policy：使用当前行为策略实际选出的下一动作
DQN用神经网络近似 Q(s,a)状态太多时无需逐项存表；学习补充：经验回放和目标网络用于缓解训练不稳定

On-policy 不是“在线”，off-policy 也不是“离线”。判断依据是产生数据的行为策略与被学习的目标策略的关系。Q-learning 能使用 ε-greedy 数据，不等于只从随机动作学习。

Exploration Exploitation Strategies & Discount Factor

本章图表 / 方法：ε-greedy 概率、α / γ / ε 对照与网格价值评估（第 16–20 页）。

参数控制什么调大意味着什么
α 学习率一次新经验改变旧估计的幅度更新更快，但可能更波动
γ 折扣因子未来奖励在当前回报中的权重更重视较远的未来；不是探索更多
ε 探索概率随机选择动作的比例更多尝试未知选择，短期得分可能降低

回报 Gₜ = rₜ₊₁ + γrₜ₊₂ + γ²rₜ₊₃ + …。两步奖励为 −1、10，γ = 0.9，回报是 8；不是把第一步也乘 γ。γ = 0 只看即时奖励；持续任务常用 γ < 1。

ε-greedy：以 1−ε 选当前估计最好的动作，以 ε 在全部动作中均匀随机选择。若只有两个动作且最优动作唯一，ε = 0.2 时，最优动作总概率为 0.8 + 0.2/2 = 0.9，另一个为 0.1。探索也可能抽中最优动作。

固定策略的价值评估，不是在选最佳动作

Vnew(s) = Σₐ π(a|s) [r(s,a,s′) + γ Vold(s′)]（此处假设动作后的转移确定）。四个动作等概率时，分别算四个结果再取平均。同步更新时全部使用同一份旧 V 表。

核对说明：按截图中的四项直接计算，0.25×(−1)+0.25×(−1)+0.25×(−1)+0.25×(−1+0.9×10) = +1.25，不是 −1.25。这只修正截图算术，不替练习决定终点规则。若到达终点获得 +10 后回合结束，应将之后价值设为 0；若题目用固定 V(G)=10 表达边界条件，必须说明即时奖励的约定，避免把终点奖励算两遍。

Multi-Armed Bandit Problem

本章图表 / 方法：三台老虎机、增量均值与累计奖励图（第 21 页；Multi_Armed_Bandit_Problem.ipynb）。

多臂老虎机的“臂”就是一个可选动作。每个动作的奖励分布未知，要在有限次数中平衡试新选项和使用已知好选项。经典平稳 bandit 没有需要规划的状态转移；它不是完整网格世界 Q-learning。

Notebook 设真实成功概率为 [0.2, 0.7, 0.4]，每轮返回 0 或 1，ε = 0.1，运行 1000 轮。环境用真实概率产生奖励；agent 只用自己观察到的奖励估计 Q，不能直接读取真实概率来选动作。

import numpy as np

# 根据课堂 Notebook 整理：固定种子，使演示可复现。
rng = np.random.default_rng(42)
true_probabilities = np.array([0.2, 0.7, 0.4])  # 环境参数
q_values = np.zeros(3)                        # agent 的估计
counts = np.zeros(3, dtype=int)
rewards = []
epsilon = 0.1
for _ in range(1000):
    if rng.random() < epsilon:
        action = int(rng.integers(3))
    else:
        # 平局时随机打破，避免总选数组中第一项。
        best = np.flatnonzero(q_values == q_values.max())
        action = int(rng.choice(best))
    reward = int(rng.random() < true_probabilities[action])
    counts[action] += 1
    q_values[action] += (reward - q_values[action]) / counts[action]
    rewards.append(reward)
print("估计 Q:", q_values)
print("选择次数:", counts)
print("累计奖励:", sum(rewards))

Q ← Q + (R−Q)/N 是样本均值的增量写法，N 先加 1。例如一个动作前三次奖励为 1、0、1，Q 依次为 1、0.5、2/3。概率、Q 和频次是三种不同数据。

读图时看：累计奖励曲线的斜率、最终 Q 与真实概率的差、各动作被选择次数。原 Notebook 的柱状图只对比最终估计，不能单凭它声称展示了“收敛过程”；1000 次有限采样也不保证每个动作都探索充分。

Reinforcement Learning with Human Feedback

本章图表 / 方法：人类示范 → SFT → 偏好排序 → 奖励模型 → 策略优化（第 22–27 页）。

以问答为例：先收集高质量示范，做监督微调（SFT）；再让人比较同一问题的多个回答，学习一个能预测偏好的奖励模型；最后让语言模型通过 RL 提高回答的预期奖励。语言模型是生成回答的策略，奖励模型负责给反馈，两者不是同一个角色。

阶段输入输出 / 学习目标
SFT问题与示范答案提高示范答案的生成概率
Reward model同题回答及偏好排序学习哪个回答更符合标注者偏好
RL 优化策略生成的回答与奖励分数更新策略，兼顾奖励及对原策略的偏离约束
核对说明：RAG 是检索资料后作为上下文提供给模型，本身不等于微调权重；SFT 也不是“按与人类答案相似度直接给 RL 奖励”。RLHF 主要描述训练过程，不意味着每次回答前都在线更新参数。偏好奖励只是近似目标，不能保证事实正确或消除全部偏差。

Challenges, Future Directions & GRPO

本章图表 / 方法：交互成本、泛化、多智能体与课件 GRPO 公式（第 28–29 页）。

挑战为什么难应检查什么
样本效率 / 计算成本大量交互才能学到有效策略预算、模拟器差距、学习曲线
稳定性 / 收敛估计目标与数据分布随策略一起变化多种随机种子、回报波动、失败率
奖励与伦理代理指标可能被利用奖励漏洞、安全边界、群体结果

课件提出深度 RL、迁移学习、多智能体协作和稳健泛化等方向。学习补充：多智能体环境中，其他 agent 也在改变策略，因此一个 agent 看到的环境可能随训练变化。

读公式先抓四件事：同一问题生成一组回答；用组内奖励均值和标准差得到相对优势；提高相对更好回答的概率；用裁剪与 KL 约束控制更新幅度。G 是组大小，Â 是标准化后的相对优势，ε 是裁剪范围，β 是 KL 权重。这里 ε 不是 ε-greedy 的探索率。

GRPO 用组内比较估计基线，不需要单独的 critic 价值模型，但仍需奖励信号。详见课件引用的 DeepSeek-R1 论文 §2.2.1；这是概念扩展，不把论文性能数字当作课程实验结果。

Lyft Case｜匹配司机时考虑长期价值

本章图表 / 方法：案例三页、六个配对评分与 switchback 实验。

讲义提出：同样的车费，不同终点会影响下一单机会。课堂简化评分为 fare + V(终点) − V(当前位置)。这里 value 是未来收益估计，不能当作这单已经赚到的现金。

查看案例背景与结果原页

原题路线：①枚举两位司机服务不同乘客的可行配对，最小化接客总时间；②为六个司机—乘客组合算长期评分；③最大化总分，平局用接客时间打破；④比较即时车费与终点价值；⑤解释负分。不能分别替每位司机选最大值后忽略同一乘客不能被服务两次。

做完后核对：五问解析
司机R1：fare 38，终点 V=8R2：fare 14，终点 V=55R3：fare 16，终点 V=50
A，当前 V=50−41916
B，当前 V=30163936
  1. 旧系统：A→R1、B→R3，总接客时间 2+2=4 分钟，R2 等待。
  2. 六项得分如表。例如 A→R1：38+8−50=−4。
  3. 新系统：A→R2、B→R3，总分 19+36=55，接客时间 3+2=5 分钟。另一个 55 分方案 A→R3、B→R2 要 20 分钟，故不选；R1 等待。
  4. 即时车费由 54 降到 30，接客时间多 1 分钟；终点价值总和由 58 升至 105，总评分由 32 升至 55。这是基于估计的未来优势，不是已经实现的净利润。
  5. 负分表示车费不足以弥补当前位置价值的下降，不表示车费为负，也不必然表示这趟行程会亏现金。

为什么不用普通乘客 A/B 测试？

两组乘客共享司机资源，一组匹配改变司机位置，会影响另一组。讲义采用区域整体随时间切换的 switchback，并剔除切换后过渡数据。阅读报告结果时仍要问：不同地区和司机是否都受益？冷门地区是否因缺少探索而长期被低估？司机改变行为后，策略是否仍有效？

案例中的 2021 年上线、13% 未匹配请求下降等属于讲义报告的历史结果；本页的五问演算只使用课堂虚构数据，不据此推断当前 Lyft 服务表现。
