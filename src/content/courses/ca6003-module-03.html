Data Analytics: Where Does It Fit?

本章图表 / 方法：第 2–3 页：Prepare / Process / Analyze 与三项分析要求。

Data Analytics 用统计、数学和计算方法解释模式、识别趋势，支持决策；它不只出现在最后的 Analyze 阶段。Prepare 中探索数据，Process 中评估转换影响，Analyze 中回答数据科学问题。

  1. Define the Question：先定义问题，再选择分析，不从“我会哪个模型”出发。
  2. Ensure Good Data：洞察受数据质量制约。检查缺失、重复、时间覆盖和口径。
  3. Interpret Critically：理解方法、假设和限制；得到一个数还不等于回答了问题。

衔接前两周：剖析与清洗让数据可用，编码与缩放让方法能正确处理数据；第三周判断该用什么分析，以及结果意味着什么。

Diagnostic: Relationship & Dependency Analysis

本章图表 / 方法：第 7–8 页：异常与销量问题；相关、回归和特征重要性。

诊断问题包括：为什么时序里有异常？为什么销量下降？哪些因素与结果关联？关联分析帮助筛选解释，但需要进一步验证原因。

技术适合的数据 / 关系解释与误区
Pearson correlation连续数值；线性关联r∈[−1,1]，符号是方向、绝对值是线性强度；对异常值敏感
Spearman correlation有序 / 数值；单调关联按排名计算；可捕捉非线性的单调关系，不涵盖任意曲线
Linear regression连续结果与一个 / 多个预测变量系数描述在模型条件下的变化；不能直接解释为干预效果
Polynomial regression具有弯曲关系的连续结果通过多项式项表达曲线；次数太高可能过拟合
Feature importance已训练模型中的多个特征表示模型依赖程度；不是原因的排名，也不一定给出影响方向
# 学习补充：沿用上节 houses，比较 Pearson 与 Spearman
print(houses[["GrLivArea", "SalePrice"]].corr(method="pearson"))
print(houses[["GrLivArea", "SalePrice"]].corr(method="spearman"))

这个自造例子把价格设为面积的 200 倍，两种相关都为 1；结果来自生成规则，并非真实房价规律。学习补充：Pearson 接近 0 不排除 U 形关联，相关也不等于因果。

Root Cause: Fishbone & 5 Whys

本章图表 / 方法：第 9–10 页：销售看板收入偏低，五步诊断和鱼骨图。

步骤课件销售看板场景需要的证据
1 定义现象过去三天看板收入异常偏低明确日期、门店、金额口径与基准
2 探索原因按数据、流程、人员、工具列假说鱼骨图组织可能原因，尚未定论
3 深入调查晚到交易遗漏 → 导入过早 → 无后续刷新 → 工具 / 流程限制5 Whys 每一步都需记录与日志支持
4 验证根因比较源系统与看板，核对交易到达和刷新时间验证缺失交易能否解释差额
5 修复并跟踪更晚 / 增量刷新，增加完整性检查读回金额、监测后续结果

鱼骨图用于提出候选原因，5 Whys 用于深入追问；二者不能代替证据。不要看见收入下降就认定真实销量下降，也不要为凑五次“为什么”编造原因。

练习：源系统收入正常，看板缺少 20:05 后的交易。下一步是什么？

核对导入时间、源交易到达时间和刷新日志；确认缺失金额与差额是否对应，再测试晚间 / 增量刷新并检查回补结果。

Hypothesis Testing & Validation

本章图表 / 方法：第 11–12 页：认知游戏前后注意力评分；p 值、显著性水平与检验选择。

课件问题：认知游戏能否改善注意力？设 H₀：没有改善，H₁：有改善；选择符合设计的检验，计算 p 值，与预先设定的 α 比较，再检查效果大小和假设。

课件例子 p=0.03 < α=0.05，因此拒绝 H₀。学习补充：p 值是在 H₀ 和检验假设成立时，得到当前或更极端结果的概率；不是 H₀ 为真的概率，也不是“有 97% 概率游戏有效”。不拒绝 H₀ 不等于证明没有作用。

方法适用场景选择前要核对
t-test比较两个组 / 条件的均值同一人前后为配对；独立两组用独立样本设计
ANOVA比较三组或以上均值总体显著不说明哪两组不同
Chi-square类别变量是否有关联检查计数与期望频数，而非连续值均值
Correlation test两变量是否存在指定形式关联Pearson / Spearman 假设与关系形态
Regression significance预测变量与结果是否关联残差、模型设定与混杂因素
Non-parametric参数检验假设不合适Mann–Whitney U 用于独立组；Wilcoxon signed-rank 用于配对
# 学习补充：同一组参与者的前后评分，双侧配对 t 检验
import numpy as np
from scipy.stats import ttest_rel
before = np.array([50, 52, 48, 60, 55, 58, 49, 54], dtype=float)
after = np.array([53, 54, 52, 61, 58, 60, 51, 57], dtype=float)
result = ttest_rel(after, before)
print("平均变化:", (after - before).mean())
print("t:", result.statistic, "p:", result.pvalue)

这段自造数据代码不是课件 p=0.03 的计算来源。先看配对差值、分布和设计；若事先设定“改善”的单侧假设，应匹配单侧检验，不能看到结果后切换方向。没有对照组和合适研究设计，前后差异也不能排除练习效应等解释。

Predictive Analytics

本章图表 / 方法：第 13 页：学习已有模式 → 新数据 → 未知结果；回归、分类、聚类。

用已有观察拟合模型，再估计未见样本或未来结果。回归预测连续数值（房价），分类预测类别（垃圾邮件），聚类发现相似群组（客户行为）。课件把聚类纳入分析工具；聚类是无监督分组，不能直接等同于带标签的未来结果预测。

评价重点是泛化，而非只在训练集拟合得好。学习补充：先划分数据，在训练集拟合缺失处理、编码、缩放和降维；验证 / 测试只 transform。时间预测按时间划分，分类可在适当条件下分层抽样。

Prescriptive Analytics

本章图表 / 方法：第 14 页：房屋改造目标、成本和约束；规则、优化与决策树。

预测回答“可能卖多少钱”，处方回答“应该采取什么行动”。先写出目标、可选行动、成本与限制，再比较不行动、加车库、扩大面积、装修等方案。

方法课件案例边界
Rule-based没有车库且预算 ≥30,000、空间足够 → 考虑加车库规则需要领域依据和例外处理
Optimization在预算 ≤50,000 等约束下选择预期收益最佳的改造明确决策变量、目标函数与约束
Decision trees依面积、车库和预算条件逐步推荐用于行动的规则树，不自动等同于预测分类树

模型看到“有车库的房子更贵”，并不证明给任意房屋加车库都会增加同样的价格。处方建议需要验证行动效果、可行性与不确定性。

2 便宜房是否划算？相似房正常价格；便宜是否因面积、年龄、质量或地区估计该房合理售价结合风险和支出判断是否考虑购买
3 买入、翻修、转卖高价房特征；哪些属性与价值有关翻修后预期售价比较各方案预期利润
4 开发商在哪里投资？地区 / 房屋类型的历史价差及可能解释新项目预期价格在预算、需求与限制下选择方案
5 银行是否发住房贷款？抵押物业历史价格与属性估计抵押物价值结合贷款约束讨论额度和条款

Expected Profit = Expected Sale Price − Purchase Price − Renovation Cost − Other Costs。学习补充：假设售价 500,000、买价 380,000、改造 60,000、其他成本 30,000，预期利润 30,000；售价少 10% 则变为 −20,000。此为课堂假设，说明预测误差会改变行动判断。

第五个场景中，抵押物估值只是决策的一项输入，不能替代还款能力等贷款评估。相同数据集可以回答五种不同问题：先写清问题，再确定方法和输出。

Notebook Supplement · PCA Dimensionality Reduction

本章图表 / 方法：相关 Notebook：8×8 digits、标准化、二维投影、累计方差、重建、分类比较。

每张 digits 图片是 8×8 的 64 个像素特征。PCA 找到方差较大的正交方向，用较少主成分表示数据；类别标签用于给散点着色或后续分类，PCA 本身不依靠标签学习。

原 Notebook 展示 2 维投影、累计 explained variance、2/10/20/40 个主成分重建，再比较 64 维与 20 维 Logistic Regression。核对：它先对全数据 StandardScaler，再划分训练 / 测试，这不适合作为独立分类评价；以下代码先划分、用 Pipeline 在训练集拟合。

# 学习补充：修正全数据先缩放的泄漏，并避免已弃用的 multi_class 参数
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.metrics import accuracy_score

X, y = load_digits(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42
)
for components in [None, 2, 20, 40]:
    steps = [StandardScaler()]
    if components is not None:
        steps.append(PCA(n_components=components, random_state=42))
    steps.append(LogisticRegression(max_iter=2000, solver="lbfgs"))
    model = make_pipeline(*steps)
    model.fit(X_train, y_train)
    print(components, accuracy_score(y_test, model.predict(X_test)))

# 仅在训练集探查投影、累计方差与重建
scaler = StandardScaler().fit(X_train)
scaled = scaler.transform(X_train)
pca = PCA(n_components=20, random_state=42).fit(scaled)
reduced = pca.transform(scaled)
reconstructed = scaler.inverse_transform(pca.inverse_transform(reduced))
print("形状:", X_train.shape, reduced.shape, reconstructed.shape)
print("保留方差:", pca.explained_variance_ratio_.sum())
cumulative = np.cumsum(PCA().fit(scaled).explained_variance_ratio_)
print("2/10/20/40 个主成分的累计方差:", cumulative[[1, 9, 19, 39]])

n_components 越小，压缩更强，也可能丢失分类所需信息；方差保留率不是准确率，更不是公平性。PCA 需要中心化，但不强制一定用 StandardScaler；不同量纲时标准化通常合理，也会改变各特征的重要程度。原 Notebook 标准化图像的重建应先逆缩放再解释像素；运行时间也应实际测量，不能保证降维一定更快。

Notebook Supplement · Trees & Imbalanced Classification

本章图表 / 方法：相关 Notebook：two moons、类别权重、决策边界、Decision Tree / Random Forest / XGBoost。

原例生成 4,000 个非线性月牙点，保留全部类别 0 和 10% 类别 1，得到 2,000:200 的不平衡数据；再按 70% / 30% 分层划分。全判 0 就有约 90.9% accuracy，因此要比较少数类 precision、recall、F1 和混淆矩阵。

import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report, confusion_matrix

X, y = make_moons(n_samples=4000, noise=0.25, random_state=42)
rng = np.random.RandomState(42)
idx0, idx1 = np.flatnonzero(y == 0), np.flatnonzero(y == 1)
keep = np.concatenate([idx0, rng.choice(idx1, int(0.1 * len(idx1)), replace=False)])
X, y = X[keep], y[keep]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42
)
models = {
    "Decision Tree": DecisionTreeClassifier(max_depth=5, class_weight="balanced", random_state=42),
    "Random Forest": RandomForestClassifier(n_estimators=300, max_depth=6, class_weight="balanced", random_state=42),
}
for name, model in models.items():
    model.fit(X_train, y_train)
    predicted = model.predict(X_test)
    print(name, classification_report(y_test, predicted, zero_division=0))
    print(confusion_matrix(y_test, predicted))
参数 / 方法含义误区
max_depth限制单棵树深度更深通常更复杂，但边界形状不能单独证明过拟合
class_weight="balanced"权重 N/(K×N_c)，由训练标签计算加权不是增加少数类样本，也不保证每类准确率相同
Random Forest / 300 treesbootstrap 样本和随机特征训练多树，再聚合概率通常降低方差；不保证任何数据上都优于单树
XGBoost树按序拟合目标函数的梯度信息，逐步改进预测不是简单重训全部错误样本；最终要看独立评价
scale_pos_weight二分类正类损失相对权重，示例用 neg/pos≈10正类不一定总是少数类；比例是起点而非最佳值
# 可选：需要安装 xgboost；沿用上节的训练 / 测试变量
from xgboost import XGBClassifier
model = XGBClassifier(
    n_estimators=400, max_depth=4, learning_rate=0.05,
    subsample=0.9, colsample_bytree=0.9, reg_lambda=1.0,
    scale_pos_weight=(y_train == 0).sum() / (y_train == 1).sum(),
    eval_metric="logloss", random_state=42,
)
model.fit(X_train, y_train)
print(classification_report(y_test, model.predict(X_test), zero_division=0))
print(confusion_matrix(y_test, model.predict(X_test)))

learning_rate 控制每棵树贡献；subsample 是样本采样比例，colsample_bytree 是特征采样比例，reg_lambda 是 L2 正则强度。该示例只有两个特征，特征采样的影响要结合实际维度理解。

原 plot_boundary 在平面铺 350×350 网格，用 predict 后 contourf，再叠加样本点；这是可视化，不是泛化证据。不要仅凭细碎边界就断言“不是过拟合”或“XGBoost 最佳”。降低正类决策阈值通常提高召回并增加预测为正的数量，precision 是否下降取决于实际数据；阈值应在验证集选择，测试集用于最后评价。

自测与掌握标准

本章图表 / 方法：按课件问题选择方法，并指出证据限制。

1. 想知道各地区典型房价，用什么分析？

描述分析：分组统计、分布和可视化；先确认口径、样本量及极端值。

2. “面积与房价相关，所以扩建一定赚更多”哪里有问题？

关联不是干预效果，其他因素可能混杂；处方分析还需成本、约束和行动效果证据。

3. p=0.03 能说原假设为真的概率是 3% 吗？

不能。p 值是在原假设及检验假设成立时，得到当前或更极端结果的概率。

4. 销售看板异常低，鱼骨图画完就找到了根因吗？

没有。鱼骨图列候选原因；追问后仍要比较源数据和刷新日志验证，并检查修复效果。

5. PCA 保留 90% 方差，模型就有 90% accuracy 吗？

不是。保留方差衡量表示压缩，accuracy 需对带标签的独立样本评价。
