CHAPTER 04

函数：抽象、参数与作用域

函数是组织程序的核心单位。高质量函数应该职责单一、输入输出清楚、容易测试，并通过名称表达意图。

学完你应该能够：设计和调用函数；理解参数类型、返回值、作用域和可变默认参数；能把 RAG 流程拆成可测试的小函数。

必须掌握的术语

术语 准确理解
function 封装一段可复用逻辑的对象。
parameter / argument 定义函数时的形参；调用时传入的实参。
return value 函数交还给调用方的结果；没有 return 时返回 None。
positional / keyword 按位置传参与按参数名传参。
default parameter 调用时省略可使用的默认值。
*args / **kwargs 收集额外位置参数与关键字参数。
scope 名字可见的范围，包括局部和全局作用域。
pure function 结果只依赖输入且无外部副作用的函数。
docstring 函数的内置说明文档。
type hint 类型标注，帮助阅读和静态检查，不强制运行时类型。

1. 输入、处理、输出

def cosine_label(score: float, threshold: float = 0.8) -> str:
    """根据相似度返回可读标签。"""
    if not 0 <= score <= 1:
        raise ValueError("score 必须在 0 到 1 之间")
    return "相关" if score >= threshold else "不相关"

label = cosine_label(0.86, threshold=0.75)

好的函数会验证关键前置条件，并返回稳定、可预测的类型。

2. 位置参数和关键字参数

def search(query, top_k=5, min_score=0.0):
    return {"query": query, "top_k": top_k, "min_score": min_score}

search("什么是 RAG", 3)
search("什么是 RAG", top_k=3, min_score=0.7)

3. 多个返回值本质是 tuple

def split_train_test(data, ratio=0.8):
    cut = int(len(data) * ratio)
    return data[:cut], data[cut:]

train, test = split_train_test(list(range(10)))

4. 作用域

model_name = "qwen"       # 全局名字

def build_config():
    temperature = 0.2     # 局部名字
    return {"model": model_name, "temperature": temperature}

函数内部读取全局配置是允许的，但大量依赖隐藏的全局状态会让测试和复现变困难。更好的方式是显式传参。

5. 可变默认参数陷阱

# 错误：同一个 list 会在多次调用间共享
def add_item_bad(item, items=[]):
    items.append(item)
    return items

# 正确
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

6. 拆分 RAG 流程

def load_documents(path): ...
def chunk_documents(documents, chunk_size=500): ...
def embed_chunks(chunks, model): ...
def retrieve(query, index, top_k=5): ...
def build_prompt(query, hits): ...
def generate_answer(prompt, llm): ...

这种拆分让每一步都能单独测试、替换和记录指标。

常见错误

  • 函数既读文件、调用模型、打印结果又修改全局变量，职责过多。
  • 忘记 return，调用方得到 None。
  • 修改传入的 list/dict，却没有在函数名或文档中说明副作用。
  • 使用可变默认参数。
  • 捕获所有异常后直接返回空值，掩盖真正错误。
  • 函数名使用模糊的 process_data，无法表达具体动作。
