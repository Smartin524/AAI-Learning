Pandas 常用方法

常用调用格式与一句用途。import pandas as pd；df 为 DataFrame，s 为 Series。以下展示常用参数组合。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。以下列出常用调用写法，默认值与示例值以条目说明为准。

创建、读取与查看

  • pd.DataFrame(data, index=None, columns=None) — 创建表格
  • pd.Series(data, index=None, name=None) — 创建一列数据
  • pd.read_csv(filepath, sep=",", usecols=None, dtype=None) — 读取 CSV
  • pd.read_excel(io, sheet_name=0, usecols=None) — 读取 Excel
  • df.head(n=5) — 查看前 n 行
  • df.tail(n=5) — 查看后 n 行
  • df.info() — 查看列类型及非空数量
  • df.describe() — 汇总数值列统计
  • df.to_csv(path, index=False) — 保存 CSV
  • df.to_excel(path, index=False) — 保存 Excel

选择与清理

  • df.loc[row_labels, column_labels] — 按标签选择；这是索引器
  • df.iloc[row_positions, column_positions] — 按位置选择；这是索引器
  • df.query(expr) — 按表达式筛选行
  • df.drop(columns=names) — 删除指定列
  • df.rename(columns=mapping) — 重命名列
  • df.astype(dtype) — 转换类型或按列类型映射转换
  • df.isna() — 判断缺失值
  • df.fillna(value) — 填充缺失值
  • df.dropna(axis=0, how="any", subset=None) — 删除有缺失值的行或列
  • df.drop_duplicates(subset=None, keep="first") — 删除重复行
  • pd.to_numeric(arg, errors="raise") — 转换为数值
  • pd.to_datetime(arg, errors="raise", format=None) — 转换为日期时间

计算、分组与排序

  • df.sort_values(by, ascending=True) — 按列值排序
  • df.sort_index(axis=0, ascending=True) — 按索引排序
  • df.groupby(by, dropna=True) — 创建分组对象
  • grouped.agg(func) — 汇总分组；func 可为函数名、列表或字典
  • df.agg(func, axis=0) — 按列或行汇总
  • df.apply(func, axis=0) — 按列或行应用函数
  • s.map(arg) — 按映射或函数转换每个值
  • s.value_counts(normalize=False, dropna=True) — 统计各值频数或比例
  • s.unique() — 取得唯一值
  • s.nunique(dropna=True) — 统计唯一值数量
  • df.sample(n=1, random_state=None) — 随机抽取行

合并与重塑

  • pd.concat(objs, axis=0, ignore_index=False) — 按行或列拼接
  • pd.merge(left, right, how="inner", on=None) — 按键连接表格
  • df.join(other, on=None, how="left") — 连接表格，默认按索引
  • df.pivot(index=rows, columns=cols, values=values) — 长表转宽表，重复组合会报错
  • df.pivot_table(values=values, index=rows, columns=cols, aggfunc="mean") — 透视并汇总重复组合
  • df.melt(id_vars=None, value_vars=None, var_name=None, value_name="value") — 宽表转长表
  • df.set_index(keys, drop=True) — 将列设为索引
  • df.reset_index(drop=False) — 重置索引
