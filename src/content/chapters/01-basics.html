内置函数与类型转换

常用调用格式与一句用途。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。以下列出常用调用写法，默认值与示例值以条目说明为准。

类型转换

  • int(x) — 转整数
  • int(text, base=10) — 按进制解析整数文本
  • float(x) — 转浮点数
  • str(obj) — 转字符串
  • bool(x) — 转布尔值
  • list(iterable) — 转列表；list() 创建空列表
  • tuple(iterable) — 转元组；tuple() 创建空元组
  • set(iterable) — 转集合；set() 创建空集合
  • dict(mapping_or_pairs) — 转字典；dict() 创建空字典
  • bytes(text, encoding="utf-8") — 文本转字节
  • complex(real, imag=0) — 创建复数

数字与进制

  • abs(x) — 绝对值
  • round(number, ndigits=None) — 四舍六入五成双，保留指定位数
  • pow(base, exp) — 乘方
  • pow(base, exp, mod) — 模幂
  • divmod(a, b) — 返回商和余数
  • bin(n) — 二进制字符串
  • oct(n) — 八进制字符串
  • hex(n) — 十六进制字符串
  • ord(char) — 字符转 Unicode 码点
  • chr(codepoint) — 码点转字符

类型与对象查询

  • type(obj) — 查询类型
  • isinstance(obj, type_or_tuple) — 判断对象类型
  • issubclass(cls, class_or_tuple) — 判断子类关系
  • callable(obj) — 判断能否调用
  • getattr(obj, name, default) — 读取属性，不存在时返回 default
  • setattr(obj, name, value) — 设置属性
  • hasattr(obj, name) — 判断属性是否存在
  • delattr(obj, name) — 删除属性
  • dir(obj) — 列出属性名
  • vars(obj) — 取得对象的属性字典
  • id(obj) — 取得对象标识
  • hash(obj) — 取得可哈希对象的哈希值

输入、输出与帮助

  • print(*objects, sep=" ", end="\n", file=None, flush=False) — 打印多个对象
  • input(prompt="") — 读取一行文本
  • repr(obj) — 取得调试用字符串
  • format(value, format_spec="") — 按格式说明格式化值
  • help(obj) — 查看帮助
  • breakpoint() — 进入调试器
