Matplotlib 常用方法

常用调用格式；用途写在代码注释中。import matplotlib.pyplot as plt；fig、ax 来自 plt.subplots()。参数中的颜色、标签等是示例值。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。以下代码块为独立调用速查，变量需替换为你的数据，不应整块顺序运行；默认值与示例值以注释为准。

画布

# 创建画布
plt.figure(figsize=(8, 5), dpi=100)

# 返回画布和坐标轴
plt.subplots(nrows=1, ncols=1, figsize=(8, 5))
# 添加子图
fig.add_subplot(nrows, ncols, index)

# 自动调整间距
fig.tight_layout()

常见图形

# 折线图
ax.plot(x, y, color="C0", linestyle="-", marker="o", label="data")

# 散点图
ax.scatter(x, y, s=20, c="C0", alpha=0.7)

# 柱状图
ax.bar(x, height, width=0.8, label="data")

# 横向柱状图
ax.barh(y, width, height=0.8)

# 直方图
ax.hist(x, bins=10, density=False, alpha=0.7)
# 箱线图
ax.boxplot(x)

# 饼图
ax.pie(x, labels=labels, autopct="%1.1f%%")

# 图像或热力图
ax.imshow(X, cmap="viridis", aspect="auto")

# 填充两条曲线之间区域
ax.fill_between(x, y1, y2=0, alpha=0.3)

标题、坐标与图例

# 设置子图标题
ax.set_title(label)

# 设置 x 轴名称
ax.set_xlabel(label)

# 设置 y 轴名称
ax.set_ylabel(label)

# 设置 x 轴范围
ax.set_xlim(left=None, right=None)

# 设置 y 轴范围
ax.set_ylim(bottom=None, top=None)

# 设置 x 轴刻度及文本
ax.set_xticks(ticks, labels=None)
# 设置 y 轴刻度及文本
ax.set_yticks(ticks, labels=None)

# 显示图例
ax.legend(loc="best")

# 显示网格
ax.grid(visible=True, axis="both", alpha=0.3)

# 添加注释
ax.annotate(text, xy, xytext=None, arrowprops=None)

# 为 imshow 等返回对象添加色标
fig.colorbar(mappable, ax=ax)

# 设置整张画布标题
fig.suptitle(text)

显示与保存

# 显示图形
plt.show()

# 保存图片
fig.savefig(fname, dpi=300, bbox_inches="tight")
# 关闭画布
plt.close(fig)
