PYTHON REFERENCE · 02

容器：list、dict、set、tuple

常用调用格式与一句用途。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。以下列出常用调用写法，默认值与示例值以条目说明为准。

列表 list

  • items.append(value) — 末尾追加一个元素
  • items.extend(iterable) — 末尾追加多个元素
  • items.insert(index, value) — 在索引处插入
  • items.remove(value) — 删除首个匹配值
  • items.pop(index=-1) — 删除并返回指定元素
  • items.index(value, start, stop) — 在指定范围查找首个索引；start、stop 可省略
  • items.count(value) — 统计出现次数
  • items.sort(key=None, reverse=False) — 原地排序，返回 None
  • items.reverse() — 原地反转，返回 None
  • items.copy() — 浅复制
  • items.clear() — 清空列表

字典 dict

  • d.get(key, default=None) — 读取键，不存在时返回默认值
  • d.keys() — 取得键视图
  • d.values() — 取得值视图
  • d.items() — 取得键值对视图
  • d.update(other, **kwargs) — 合并键值对，原地更新
  • d.setdefault(key, default=None) — 键不存在时写入默认值，返回该键的值
  • d.pop(key, default) — 删除并返回值；可省略 default，缺键时报错
  • d.popitem() — 删除并返回最后插入的键值对
  • d.copy() — 浅复制
  • d.clear() — 清空字典
  • dict.fromkeys(iterable, value=None) — 用多个键创建字典，共享同一个 value

集合 set

  • s.add(value) — 添加一个元素
  • s.update(*iterables) — 添加多个集合或可迭代对象的元素
  • s.remove(value) — 删除元素，不存在时报错
  • s.discard(value) — 删除元素，不存在时忽略
  • s.pop() — 删除并返回任意一个元素
  • s.union(*others) — 返回并集
  • s.intersection(*others) — 返回交集
  • s.difference(*others) — 返回差集
  • s.symmetric_difference(other) — 返回对称差集
  • s.intersection_update(*others) — 原地保留交集
  • s.difference_update(*others) — 原地删除其他集合中的元素
  • s.symmetric_difference_update(other) — 原地改为对称差集
  • s.issubset(other) — 是否为子集
  • s.issuperset(other) — 是否为超集
  • s.isdisjoint(other) — 是否没有共同元素
  • s.copy() — 浅复制
  • s.clear() — 清空集合

元组与序列

  • t.count(value) — 统计元组中的出现次数
  • t.index(value, start, stop) — 查找元组中的首个索引；start、stop 可省略
  • len(sequence) — 取得元素数量
  • sequence[start:stop:step] — 切片；边界不包含 stop，三项均可省略
