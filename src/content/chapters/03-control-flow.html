字符串常用方法

常用调用格式；用途写在代码注释中。s 表示字符串。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。以下代码块为独立调用速查，变量需替换为你的数据，不应整块顺序运行；默认值与示例值以注释为准。

大小写与清理

# 转小写
s.lower()

# 转大写
s.upper()

# 首字母大写，其余小写
s.capitalize()

# 每个单词首字母大写
s.title()

# 交换大小写
s.swapcase()

# 用于忽略大小写的文本比较
s.casefold()
# 去除两端指定字符集合；默认空白
s.strip(chars=None)

# 去除左端指定字符集合
s.lstrip(chars=None)

# 去除右端指定字符集合
s.rstrip(chars=None)

# 移除完整前缀（Python 3.9+）
s.removeprefix(prefix)

# 移除完整后缀（Python 3.9+）
s.removesuffix(suffix)

查找与替换

# 找首个位置，未找到返回 -1；边界可省略
s.find(sub, start, end)

# 从右侧查找；边界可省略
s.rfind(sub, start, end)

# 找首个位置，未找到报错；边界可省略
s.index(sub, start, end)

# 统计子串次数；边界可省略
s.count(sub, start, end)
# 判断前缀；边界可省略
s.startswith(prefix, start, end)

# 判断后缀；边界可省略
s.endswith(suffix, start, end)

# 替换子串；省略 count 时全部替换
s.replace(old, new, count)

拆分、拼接与格式化

# 按分隔符拆分；默认按空白
s.split(sep=None, maxsplit=-1)

# 从右侧开始拆分
s.rsplit(sep=None, maxsplit=-1)

# 按行拆分
s.splitlines(keepends=False)

# 拆成分隔符前、分隔符、分隔符后
s.partition(sep)

# 按最后一个分隔符拆分
s.rpartition(sep)

# 用分隔符连接字符串序列
separator.join(strings)

# 填入花括号占位符
s.format(*args, **kwargs)
# 右侧填充
s.ljust(width, fillchar=" ")

# 左侧填充
s.rjust(width, fillchar=" ")

# 居中填充
s.center(width, fillchar=" ")

# 左侧补零
s.zfill(width)

# 编码为 bytes
s.encode(encoding="utf-8", errors="strict")

# 将 bytes 解码为字符串
b.decode(encoding="utf-8", errors="strict")

内容判断

# 是否全部为字母且非空
s.isalpha()

# 是否全部为数字字符且非空
s.isdigit()

# 是否全部为十进制数字字符且非空
s.isdecimal()

# 是否全部为数值字符且非空
s.isnumeric()

# 是否全部为字母或数字且非空
s.isalnum()
# 是否全部为空白且非空
s.isspace()

# 有大小写的字符是否均为小写
s.islower()

# 有大小写的字符是否均为大写
s.isupper()

# 是否符合标识符格式；不排除关键字
s.isidentifier()
