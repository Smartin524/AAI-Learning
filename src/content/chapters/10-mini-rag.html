数学、随机、日期与正则

常用调用格式与一句用途。先导入 math、random、statistics、re、collections；日期使用 from datetime import datetime, timedelta。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。以下列出常用调用写法，默认值与示例值以条目说明为准。

数学与统计

  • math.sqrt(x) — 平方根
  • math.ceil(x) — 向上取整
  • math.floor(x) — 向下取整
  • math.log(x, base) — 对数；省略 base 时为自然对数
  • math.log10(x) — 以 10 为底的对数
  • math.exp(x) — e 的 x 次方
  • math.sin(x) — 正弦，输入弧度
  • math.cos(x) — 余弦，输入弧度
  • math.radians(degrees) — 角度转弧度
  • math.isclose(a, b, rel_tol=1e-9, abs_tol=0.0) — 判断数值是否接近
  • statistics.mean(data) — 均值
  • statistics.median(data) — 中位数
  • statistics.stdev(data) — 样本标准差

随机与计数

  • random.seed(a=None) — 设置随机种子
  • random.random() — 返回 [0, 1) 随机浮点数
  • random.randint(a, b) — 随机整数，包含两端
  • random.randrange(start, stop, step=1) — 从整数范围抽样，不含 stop
  • random.uniform(a, b) — 在两端之间抽取浮点数
  • random.choice(sequence) — 随机取一项
  • random.choices(population, weights=None, k=1) — 有放回抽样
  • random.sample(population, k) — 无放回抽样
  • random.shuffle(items) — 原地打乱列表
  • collections.Counter(iterable) — 创建计数器
  • counter.most_common(n=None) — 按频数取前 n 项
  • collections.defaultdict(default_factory) — 创建带默认值工厂的字典
  • collections.deque(iterable=(), maxlen=None) — 创建双端队列

日期与时间

  • datetime.now(tz=None) — 当前日期时间
  • datetime(year, month, day, hour=0, minute=0, second=0) — 创建日期时间
  • datetime.strptime(text, format) — 按格式解析日期字符串
  • dt.strftime(format) — 按格式输出日期字符串
  • datetime.fromisoformat(text) — 解析 ISO 日期时间
  • dt.isoformat(sep="T", timespec="auto") — 转 ISO 日期时间文本
  • datetime.fromtimestamp(timestamp, tz=None) — 时间戳转日期时间
  • dt.timestamp() — 日期时间转时间戳
  • timedelta(days=0, seconds=0, hours=0, minutes=0) — 创建时间间隔

正则表达式

  • re.search(pattern, string, flags=0) — 查找首个匹配，返回 Match 或 None
  • re.match(pattern, string, flags=0) — 从字符串开头匹配
  • re.fullmatch(pattern, string, flags=0) — 匹配整个字符串
  • re.findall(pattern, string, flags=0) — 返回全部匹配结果
  • re.finditer(pattern, string, flags=0) — 返回 Match 迭代器
  • re.sub(pattern, repl, string, count=0, flags=0) — 替换匹配内容
  • re.split(pattern, string, maxsplit=0, flags=0) — 按正则拆分
  • re.compile(pattern, flags=0) — 编译可复用的正则对象
  • match.group(*groups) — 取得匹配内容；无参数时为完整匹配
  • re.escape(pattern) — 转义正则特殊字符
