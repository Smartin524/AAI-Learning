路径、系统与复制

常用调用格式；用途写在代码注释中。from pathlib import Path；其余工具先导入 os、shutil、copy 或 subprocess。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。以下代码块为独立调用速查，变量需替换为你的数据，不应整块顺序运行；默认值与示例值以注释为准。

构造与查询路径

# 创建路径对象
Path(path)

# 当前工作目录
Path.cwd()

# 用户主目录
Path.home()

# 转为绝对路径并解析符号链接
p.resolve()

# 路径是否存在
p.exists()

# 是否为文件
p.is_file()

# 是否为目录
p.is_dir()

# 拼接路径
p.joinpath(*parts)

# 替换文件名
p.with_name(name)

# 替换扩展名
p.with_suffix(suffix)

目录与文件操作

# 遍历目录直接子项
p.iterdir()

# 按模式查找
p.glob(pattern)

# 递归查找
p.rglob(pattern)

# 创建目录
p.mkdir(mode=0o777, parents=False, exist_ok=False)

# 重命名或移动
p.rename(target)

# 删除文件或符号链接
p.unlink(missing_ok=False)

# 删除空目录
p.rmdir()

# 读取文本
p.read_text(encoding="utf-8")

# 覆盖写入文本
p.write_text(text, encoding="utf-8")

# 读取二进制
p.read_bytes()

# 覆盖写入二进制
p.write_bytes(data)

系统与进程

# 读取环境变量
os.getenv(key, default=None)

# 当前工作目录
os.getcwd()

# 切换工作目录
os.chdir(path)

# 列出目录项名称
os.listdir(path=".")

# 递归取得目录、子目录与文件名
os.walk(top)

# 以参数列表运行命令并取得结果
subprocess.run(args, capture_output=True, text=True, check=True)

复制与移动

# 复制文件并尽可能保留元数据
shutil.copy2(src, dst)

# 复制目录树
shutil.copytree(src, dst, dirs_exist_ok=False)

# 移动文件或目录
shutil.move(src, dst)

# 递归删除目录及全部内容
shutil.rmtree(path)

# 浅复制
copy.copy(obj)

# 深复制
copy.deepcopy(obj)
