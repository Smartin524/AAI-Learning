PYTHON REFERENCE · 05

文件、JSON 与 CSV

文件对象记作 f；open() 无需导入。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。

导入方式

import json
import csv

打开与关闭

# 打开文本文件；模式 r 读、w 覆盖写、a 追加、x 新建
open(path, mode="r", encoding="utf-8")

# 读取二进制文件；wb 写入二进制
open(path, mode="rb")
# 关闭文件
f.close()

# 刷新 Python 写入缓冲区
f.flush()

读写与定位

# 读取指定长度；-1 读取剩余全部内容
f.read(size=-1)

# 读取一行
f.readline(size=-1)

# 读取多行，返回列表
f.readlines(hint=-1)

# 写入内容，类型应与打开模式一致
f.write(text_or_bytes)
# 写入多项内容，不自动补换行
f.writelines(lines)

# 移动位置；文本模式一般使用 0 或 tell() 返回值
f.seek(offset, whence=0)

# 返回当前位置
f.tell()

JSON

# JSON 字符串转 Python 对象
json.loads(text)

# Python 对象转 JSON 字符串
json.dumps(obj, ensure_ascii=False, indent=2)
# 从文件读取 JSON
json.load(f)

# 将对象写入 JSON 文件
json.dump(obj, f, ensure_ascii=False, indent=2)

CSV

# 逐行读取，文件用 newline="" 打开
csv.reader(f, delimiter=",")

# 创建写入器，文件用 newline="" 打开
csv.writer(f, delimiter=",")

# 写入一行
writer.writerow(row)

# 写入多行
writer.writerows(rows)
# 按列名读取为字典
csv.DictReader(f, fieldnames=None)

# 指定字段顺序创建字典写入器
csv.DictWriter(f, fieldnames)

# 写入 DictWriter 的列名行
writer.writeheader()
