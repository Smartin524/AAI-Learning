文件、JSON 与 CSV

常用调用格式与一句用途。文件对象记作 f；先 import json 或 import csv。文件使用 with open(...) as f: 管理关闭。

括号内为传入参数；name=value 为关键字传参，*args / **kwargs 为多个位置 / 关键字参数。以下列出常用调用写法，默认值与示例值以条目说明为准。

打开与关闭

  • open(path, mode="r", encoding="utf-8") — 打开文本文件；模式 r 读、w 覆盖写、a 追加、x 新建
  • open(path, mode="rb") — 读取二进制文件；wb 写入二进制
  • f.close() — 关闭文件
  • f.flush() — 刷新 Python 写入缓冲区

读写与定位

  • f.read(size=-1) — 读取指定长度；-1 读取剩余全部内容
  • f.readline(size=-1) — 读取一行
  • f.readlines(hint=-1) — 读取多行，返回列表
  • f.write(text_or_bytes) — 写入内容，类型应与打开模式一致
  • f.writelines(lines) — 写入多项内容，不自动补换行
  • f.seek(offset, whence=0) — 移动位置；文本模式一般使用 0 或 tell() 返回值
  • f.tell() — 返回当前位置

JSON

  • json.loads(text) — JSON 字符串转 Python 对象
  • json.dumps(obj, ensure_ascii=False, indent=2) — Python 对象转 JSON 字符串
  • json.load(f) — 从文件读取 JSON
  • json.dump(obj, f, ensure_ascii=False, indent=2) — 将对象写入 JSON 文件

CSV

  • csv.reader(f, delimiter=",") — 逐行读取，文件用 newline="" 打开
  • csv.writer(f, delimiter=",") — 创建写入器，文件用 newline="" 打开
  • writer.writerow(row) — 写入一行
  • writer.writerows(rows) — 写入多行
  • csv.DictReader(f, fieldnames=None) — 按列名读取为字典
  • csv.DictWriter(f, fieldnames) — 指定字段顺序创建字典写入器
  • writer.writeheader() — 写入 DictWriter 的列名行
