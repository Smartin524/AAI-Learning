Basic NN

理解神经元的最小教学模型

输入
少量向量或单个数
核心
Linear：Wx+b，再过激活函数
输出
分类或回归结果
重点
weight、bias、ReLU、forward

主要 API · PyTorch

nn.Linear(in_features, out_features)
全连接层：计算 Wx+b；参数量为输入数×输出数+输出数。
nn.ReLU() / torch.relu(x)
激活：负数变 0，正数保留；引入非线性，不更新权重。
forward(self, x)
自定义输入如何变成预测；通常通过 model(X) 调用。

FCNN

多层全连接神经网络

输入
固定长度向量；图片通常先 Flatten
核心
每个神经元连接上一层全部输出
输出
MNIST 为 10 个 logits
局限
展平后不再显式利用局部空间结构

主要 API · PyTorch

nn.Flatten(start_dim=1)
保留 batch，把每个样本展平；(N,1,28,28) → (N,784)。表格向量通常无需展平。
nn.Linear(784, 128)
把 784 个输入特征映射为 128 个输出；之后可接 nn.ReLU()。
nn.Sequential(...)
按顺序组合 Flatten、Linear、ReLU 等层。
nn.Linear(128, K)
生成 K 类 logits；分类训练可交给 nn.CrossEntropyLoss()。

CNN

专门提取局部空间特征

输入
图像：batch × channel × H × W
核心
卷积核扫描局部区域并共享参数
Pooling
缩小特征图，保留显著响应
重点
输出尺寸、参数量、kernel、stride、padding

主要 API · PyTorch

nn.Conv2d(3, 16, kernel_size=3)
从 3 个输入通道提取 16 个输出通道；kernel_size、stride、padding 控制局部计算与尺寸。
nn.ReLU()
对卷积输出逐元素加入非线性。
nn.MaxPool2d(2)
默认步幅为 2，每个 2×2 区域取最大值；通常缩小高宽，不改变通道数，无可训练参数。
nn.Flatten(1) → nn.Linear(...)
按样本展平，再分类；Linear 输入数应等于展平后的特征数。

RNN

沿时间顺序传递 hidden state

输入
序列：(N, T, F)，此处采用 batch_first=True
核心
当前输入 + 上一步 hidden state
共享
所有时间步使用同一套参数
重点
many-to-one、隐藏状态、梯度消失

主要 API · PyTorch

nn.RNN(input_size, hidden_size, batch_first=True)
序列输入 (N,T,F)；input_size=F，hidden_size 是隐藏状态维度，不是时间步数。
output, h_n = rnn(x)
返回各时间步输出和末尾隐藏状态；单层单向时 output 为 (N,T,H)，h_n 为 (1,N,H)。
nn.LSTM(...) / nn.GRU(...)
常见循环网络变体；LSTM 另外返回 cell state：output, (h_n, c_n)。
nn.Linear(hidden_size, K)
将序列表示映射为类别得分或回归值；选最后时间步是常见 many-to-one 做法。

人脸与物种识别，怎么选？

先判断输入是图片、表格特征还是序列，再选择结构。

任务与输入典型选择为什么 / 输出
人脸照片：判断是谁、是否同一人CNN 提取特征提取人脸特征向量 embedding，再比较相似度；固定身份集合也可以做分类。人脸检测“脸在哪里”是另一项任务。
动物、植物照片：识别物种CNN + 分类层利用形状、纹理、颜色等空间特征，输出各物种得分。
花瓣长宽等数值：识别物种FCNN；也可用传统分类器输入是固定长度特征向量，例如 Iris 的 4 个测量值；并非所有物种识别都必须用 CNN。
连续声音特征、传感器时间序列RNN / LSTM / GRU 是可选方法利用前后时间关系；选择依据是数据的序列结构。

考试在这几种结构中选择：人脸图片、物种图片通常选 CNN；表格测量值可选 FCNN。CNN 后面可以接全连接层，二者并不互斥。Basic NN 是本页的教学称呼，不是与 FCNN 严格分离的架构类别。

考试重点 · 逐点讲解

先理解概念，再跟着例子计算。四节默认展开；这些是复习重点，不代表全部都在老师确认的考试范围内。

1Basic NN

1. Weight、bias、ReLU 分别做什么？

一个神经元先计算 z = w₁x₁ + w₂x₂ + b。输入 x 是数据；weight（权重）控制每个输入怎样影响输出；bias（偏置）调整整体偏移。权重和偏置通常通过训练学习。

ReLU 再计算 a = max(0, z)：负数变 0，正数保留。它引入非线性，使网络能够表达复杂关系；普通 ReLU 本身没有可训练参数。

手算一次 forward

输入 x₁=2、x₂=3；权重 w₁=0.5、w₂=−1；偏置 b=1。

z = 0.5×2 + (−1)×3 + 1 = −1
经过 ReLU：a = max(0, −1) = 0。

2. Forward、backward、step 的区别

Forward：用当前参数把 X 变成预测。Loss：把预测与真实目标 Y 比较，得到误差。Backward：计算损失对参数的梯度。Step：优化器根据梯度修改参数。

清除旧梯度 → model(X) → loss(预测, Y) → loss.backward() → optimizer.step()

最简单的 SGD：新权重 = 旧权重 − 学习率 × 梯度。例如权重 2、学习率 0.1、梯度 0.5，更新后为 1.95。这与前向计算是两个不同阶段。

易错：backward 不直接更新参数；zero_grad 清梯度，不是把权重清零。Basic NN 是这里的教学模型称呼，不是独立于 FCNN 的严格网络类别。

2FCNN

1. Flatten 为什么把 28×28 变成 784？

一张 28×28 的灰度图有 784 个像素值。Flatten 把二维排列拉成一个长度为 784 的向量，只是重新组织形状，像素数值没有消失。全连接层随后把这 784 个数当作输入特征。

保留 batch 维度

32 张灰度图：(32, 1, 28, 28) → (32, 784)
32 张 RGB 图：(32, 3, 28, 28) → (32, 2352)
PyTorch：nn.Flatten(start_dim=1)，从第 1 维开始展平，保留第 0 维的 batch。

像素顺序仍然存在，但普通全连接层不再显式利用“相邻像素组成局部区域”这一结构；CNN 则专门利用这种空间关系。

2. Linear 参数量怎么算？

每个输出节点都连接全部输入，并通常有一个自己的 bias。假设输入有 I 个特征、输出有 O 个节点：

参数量 = I×O + O

Linear(10, 5)：10×5 个权重 + 5 个偏置 = 55。
Linear(784, 128)：784×128 + 128 = 100,480。
若再接 Linear(128, 10)：128×10 + 10 = 1,290。
整个两层网络共 101,770 个参数，普通 ReLU、Flatten 不增加参数。

输入 (32, 784) 经过 Linear(784,128)，输出为 (32,128)。batch 中各样本共用同一套参数，所以参数量不乘 32。若 bias=False，只算 I×O。

3. Logits 是什么？与概率有何区别？

Logits 是模型输出的原始类别得分。可以为负，也不要求总和为 1。例如三分类 logits 为 [2, 1, 0]，第一个类别得分最高。

Softmax 把得分变成概率

pᵢ = exp(zᵢ) / Σ exp(zⱼ)
[2, 1, 0] → 约 [0.665, 0.245, 0.090]，总和为 1。
类别预测可取 argmax，得到索引 0；不需要先算 softmax 才能找到最大得分类别。

4. 交叉熵怎样衡量“错多少”？

对单标签分类、真实标签为某一个类别的情况，交叉熵为 L = −ln(p真实类别)。模型给真实类别的概率越大，损失越小。

真实类别概率 0.9：L ≈ 0.105。
真实类别概率 0.1：L ≈ 2.303。
两次预测都看“真实类别得到多少概率”，不是只看最大概率有多高。

PyTorch 的 nn.CrossEntropyLoss() 内部处理相关变换，输入应是 logits。整数标签例子：[0, 2, 1] 表示三个样本分别属于类别 0、2、1。

5. Batch、epoch、iteration 怎么区分？

Batch：一次处理的一组样本。Batch size：这一组的样本数。Epoch：完整遍历训练集一次。Iteration / step：普通训练循环中处理一个 batch 并更新一次参数。

1,000 个样本，batch size=100：每个 epoch 有 10 步。
训练 5 epochs：共 50 次参数更新。
若有 1,050 个样本且保留最后的小 batch：每轮 11 步，最后一组 50 个；若丢弃最后不完整 batch，则为 10 步。

易错：Flatten 没有学习参数；logits 不是概率；CrossEntropyLoss 前不要额外加 softmax；epoch 不是只处理一批数据。

3CNN

1. Kernel、stride、padding、channel 是什么？

Kernel（卷积核）：学习局部特征的小权重数组；常见空间大小 3×3。Stride（步幅）：窗口每次移动几格，1 表示逐格扫描，2 表示每次跨两格。

Padding（填充）：在输入边缘补值，影响输出尺寸与边缘处理；下面假设补 0。Channel（通道）：输入的灰度图通常 1 个通道，RGB 图通常 3 个；卷积后的通道是模型学到的特征，不一定对应颜色。

普通 groups=1 的卷积中，一个输出通道的卷积核会覆盖全部输入通道，对各通道的局部乘积一起求和。16 个输出通道意味着 16 组这样的卷积核。

2. 卷积具体怎么算？

单通道、一个窗口、省略 bias
输入局部       卷积核
1  2           1  0
0  1           0  1

对应相乘再相加：1×1 + 2×0 + 0×0 + 1×1 = 2。移动窗口后继续计算，得到特征图的下一个位置。卷积核的数值通常由训练学得。

3. 卷积输出高、宽怎么算？

对高和宽分别计算。普通卷积、dilation=1、两边对称填充 P 时：

输出尺寸 = floor((输入尺寸 + 2P − K) / S) + 1

K 是 kernel 大小，S 是 stride，floor 表示向下取整。
输入 28、K=3、P=0、S=1：输出 = (28−3)/1+1 = 26。
输入 28、K=3、P=1、S=1：输出 = (28+2−3)+1 = 28。
输入 28、K=3、P=1、S=2：输出 = floor(27/2)+1 = 14。

输入 (32,3,28,28) 经过 Conv2d(3,16,3,padding=1)，输出为 (32,16,28,28)：batch 不变，通道由 3 变 16，高宽保持 28。

4. 卷积参数量怎么算？

普通 groups=1、有 bias：K高×K宽×C输入×C输出 + C输出

3×3 卷积、3 输入通道、16 输出通道：
权重 = 3×3×3×16 = 432；偏置 = 16；共 448 个参数。

同一卷积核在不同空间位置复用，所以参数量不乘图像高宽，也不乘 batch size。无 bias 时去掉最后一项；分组卷积不直接套此公式。

5. Pooling 怎样压缩信息？

局部区域
1  5
3  2

Max pooling：取最大值 → 5。
Average pooling：取平均值 → 2.75。

MaxPool2d(2) 默认 stride=2、padding=0，通常把高宽减半。它在每个通道中分别处理，通道数不变，没有可训练参数。最大池化保留局部最强响应，但会丢失部分细节和位置信息。

6. 串起来看：每一步的作用和 shape

输入 RGB 图片       (32, 3, 28, 28)
Conv2d(3,16,3,padding=1)
→ 提取局部特征       (32,16,28,28)
ReLU
→ 引入非线性         (32,16,28,28)
MaxPool2d(2)
→ 缩小高宽           (32,16,14,14)
Flatten(1)
→ 按样本展开         (32,3136)
Linear(3136,10)
→ 输出 10 类 logits  (32,10)

3136 = 16×14×14。最后全连接层有 3136×10+10=31,370 个参数；加上卷积的 448，示例网络共 31,818 个参数。

易错：卷积不一定缩小尺寸，取决于设置；ReLU 不改变 shape；池化通常不改通道数；Dense 就是这里的全连接层。上面是教学示例顺序，并非所有 CNN 都必须含 Flatten 或池化。

4RNN

1. (samples, timesteps, features) 怎么读？

例如用连续 7 天的温度、湿度、风速预测下一天销量，每个样本是一段 7 天的序列，每个时间步有 3 个特征。

输入 shape = (16, 7, 3)

16：这一批有 16 个序列样本。
7：每个样本有 7 个时间步。
3：每个时间步有 3 个测量值。
这里采用 PyTorch batch_first=True；默认 batch_first=False 时，输入通常排列为 (T,N,F)。

input_size=3，不是 7，也不是 16。hidden_size 是模型隐藏状态的长度，由网络设计决定。

2. Hidden state 怎样传递信息？

每到一个时间步，RNN 同时读取当前输入 xₜ 和前一步的隐藏状态 hₜ₋₁，生成新的隐藏状态 hₜ。隐藏状态是模型学到的历史信息表示，并非把全部历史原封不动保存下来。

hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)

第 1 天：当前天气 + 初始状态 → h₁
第 2 天：当前天气 + h₁ → h₂
……
第 7 天：当前天气 + h₆ → h₇

这是合并 bias 的教学公式。初始状态常设为 0，也可以传入；不同独立样本之间不必保留状态。隐藏状态会随输入变化。

3. 时间步共享参数是什么意思？

第 1 天、第 2 天直到第 7 天，用的是同一组 Wₓ、Wₕ 和 bias。变化的是输入与隐藏状态，不是每个时间步各有一套新权重。

同一 RNN 层从处理 7 天改为处理 14 天，循环层的参数数量不会因此翻倍；但计算量和需要处理的中间状态通常会增加。

对于单层、单向、hidden_size=8 的普通 RNN，输入 (16,7,3) 得到 output: (16,7,8) 和 h_n: (1,16,8)。batch_first 改变输入/output 排列，但不把 h_n 的 batch 移到最前。

4. Many-to-one 与 many-to-many

Many-to-one：读入多个时间步，输出一个结果。例如读完整条评论后判断正面/负面，或用过去 7 天数据预测下一天的一个数。

x₁ → x₂ → … → x₇ → 一个预测
单层单向示例：最后隐藏表示 (16,8) → Linear(8,1) → 输出 (16,1)。

Many-to-many：输入是序列，输出也是序列。例如为句子中的每个词标注词性，或给每个传感器时间步一个标签。

7 个时间步，每步预测 4 类：
RNN output (16,7,8) → 对每步应用 Linear(8,4) → (16,7,4)。

编码器—解码器也能处理输入输出长度不同的序列任务，例如翻译。不能把所有 many-to-many 都理解成长度必须相同。

5. 为什么长序列可能梯度消失？

反向传播要沿时间步把影响传回去，梯度中会出现多个导数或矩阵连乘。如果这些因素持续让数值缩小，传到很早的时间步时，梯度可能已经非常小，模型就难以学会较远的依赖关系。

只看缩小趋势的简化例子

假设每一步都乘 0.5：经过 10 步变成 0.5¹⁰≈0.00098；经过 20 步约为 0.00000095。实际 RNN 的梯度是更复杂的连乘，但这个例子说明了为什么影响可能逐步衰减。

LSTM、GRU 利用门控等机制帮助保留长期信息，缓解这个问题，但不保证无限记忆。反过来，连乘也可能导致梯度爆炸；梯度裁剪常用于控制爆炸，不能当作梯度消失的通用解决方法。

易错：时间步数不是特征数；共享参数不等于 hidden state 不变；RNN 不会自动永远记住所有历史；最后一步表示用于 many-to-one 是常见做法，不是唯一做法。

最重要的共同点

网络结构决定 forward 怎样计算；loss 定义“错多少”；backward 求梯度；optimizer 才真正修改参数。
